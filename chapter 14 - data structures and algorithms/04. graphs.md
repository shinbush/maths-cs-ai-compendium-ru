# Графики

*Графики моделируют взаимоотношения и связи: от социальных сетей до дорожных карт и цепочек зависимостей. Этот файл охватывает представления, BFS, DFS, кратчайшие пути, топологическую сортировку и связные компоненты, а также шаблоны обхода и поиска путей, которые доминируют в задачах интервью графа.*

- Мы рассмотрели теорию графов в главе 12 (матрицы смежности, лапласиан, спектральные свойства) и главе 13 (деревья, планарность, раскраска). Здесь мы сосредоточимся на **алгоритмических шаблонах**: как перемещаться, искать и оптимизировать графы в коде.

- Двумя основными графовыми алгоритмами являются **BFS** и **DFS**. Почти каждая задача с графами сводится к одной из них, возможно, с модификациями. Овладев этими двумя навыками, вы сможете решить подавляющее большинство графических задач.

## Представления графов

- **Список смежности**: для каждого узла сохраняется список его соседей. Пробел: $O(|V| + |E|)$. Лучше всего подходит для разреженных графов (большинство реальных графов).

```python
# Undirected graph
graph = {
    0: [1, 2],
    1: [0, 3],
    2: [0, 3],
    3: [1, 2]
}

# From edge list
def build_graph(n, edges):
    graph = {i: [] for i in range(n)}
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)  # omit for directed
    return graph
```

- **Матрица смежности**: матрица $n \times n$, где $A[i][j] = 1$, если ребро $(i, j)$ существует. Пробел: $O(|V|^2)$. Лучше всего подходит для плотных графов или когда вам нужен поиск ребер $O(1)$.

- **Когда использовать**: список смежности практически для всего. Матрица только в том случае, если граф плотный ($|E| \approx |V|^2$) или вам нужны проверки существования ребер за постоянное время.

## Шаблон: BFS (поиск в ширину)

- BFS исследует узлы **уровень за уровнем**, используя очередь. Это алгоритм перехода для:
    – Кратчайший путь в **невзвешенных** графиках.
    - Обход по уровням
    - Поиск связанных компонентов
    - Любая проблема с запросом «минимального количества шагов»

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])

    while queue:
        node = queue.popleft()
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
```

- **Критический**: добавьте к `visited` при **постановке в очередь**, а не при исключении из очереди. Если вы пометите посещенный при исключении из очереди, один и тот же узел может быть поставлен в очередь несколько раз от разных предшественников, что приведет к потере времени и потенциально приведет к неверным результатам.

### Легко: количество островов

- **Задача**: учитывая двумерную сетку из единиц (суша) и нулей (вода), подсчитать количество островов.

- **Шаблон**: перебор сетки. Когда вы найдете цифру «1», BFS/DFS пометит все подключенные наземные ячейки как посещенные. Каждая инициация BFS — это один остров.

```python
from collections import deque

def num_islands(grid):
    if not grid:
        return 0

    rows, cols = len(grid), len(grid[0])
    count = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                # BFS to mark entire island
                queue = deque([(r, c)])
                grid[r][c] = '0'  # mark visited
                while queue:
                    cr, cc = queue.popleft()
                    for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                        nr, nc = cr + dr, cc + dc
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == '1':
                            grid[nr][nc] = '0'
                            queue.append((nr, nc))

    return count
```

- **Подводный камень**: шаблон `directions = [(0,1),(0,-1),(1,0),(-1,0)]` для 4-связных соседей сетки используется почти в каждой сеточной задаче. Запомните это. Для 8-связности сложите диагонали.

- **Подводная ошибка**: изменение входной сетки (`grid[r][c] = '0'`) позволяет избежать необходимости использования отдельного набора `visited`. Это приемлемо на собеседованиях, но четко укажите компромисс (изменение исходных данных).

### Средний: гниющие апельсины

- **Проблема**: свежие апельсины гниют, если находятся рядом с гнилым апельсином. Возвращает минимальное время, пока все апельсины не сгниют (или -1, если это невозможно).

- **Шаблон**: BFS с несколькими источниками. Начните со всех изначально гнилых апельсинов в очереди одновременно. Каждый уровень BFS представляет собой один временной шаг.

```python
from collections import deque

def oranges_rotting(grid):
    rows, cols = len(grid), len(grid[0])
    queue = deque()
    fresh = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1

    if fresh == 0:
        return 0

    time = 0
    while queue and fresh > 0:
        time += 1
        for _ in range(len(queue)):
            cr, cc = queue.popleft()
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = cr + dr, cc + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))

    return time if fresh == 0 else -1
```

- **Ключевая информация**: BFS с несколькими источниками обрабатывает все источники одновременно. Это дает кратчайшее расстояние от *любого* источника, что равно «сколько времени пройдет до того, как сгниет последний свежий апельсин».

## Шаблон: DFS (поиск в глубину)

- DFS исследует как можно глубже, прежде чем вернуться назад. Он использует стек (явный или стек вызовов через рекурсию). DFS идеально подходит для:
    - Обнаружение цикла
    - Топологическая сортировка
    - Подключенные компоненты
    - Возврат/полный поиск
    - Поиск пути с ограничениями

```python
def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### Средний: Расписание курса (обнаружение цикла)

- **Проблема**: учитывая курсы и предварительные условия $n$, определить, можно ли пройти все курсы (т. е. нет циклических зависимостей).

- **Шаблон**: обнаружение цикла в ориентированном графе. Используйте DFS с тремя состояниями: «не посещено», «в работе» (на текущем пути DFS) и «завершено».

```python
def can_finish(num_courses, prerequisites):
    graph = {i: [] for i in range(num_courses)}
    for course, prereq in prerequisites:
        graph[course].append(prereq)

    # 0 = unvisited, 1 = in-progress, 2 = completed
    state = [0] * num_courses

    def has_cycle(node):
        if state[node] == 1:
            return True   # back edge → cycle
        if state[node] == 2:
            return False  # already fully explored

        state[node] = 1  # mark in-progress
        for neighbour in graph[node]:
            if has_cycle(neighbour):
                return True
        state[node] = 2  # mark completed
        return False

    for course in range(num_courses):
        if has_cycle(course):
            return False
    return True
```

- **Почему три состояния**: два состояния (посещенное/непосещенное) не могут отличить «Я сейчас исследую этот узел» от «Я закончил исследование этого узла». Обнаружение узла, который в данный момент исследуется (состояние = 1), означает, что мы нашли цикл. Найти тот, который полностью исследован (состояние = 2), — это просто переход, а не цикл.

### Средний: Расписание курса II (топологическая сортировка)- **Проблема**: возврат допустимого порядка курсов (топологическое упорядочение).

- **Шаблон (алгоритм Кана — на основе BFS)**: начните с узлов, у которых нет входящих ребер (входящая степень 0). Обработайте их, уменьшите степень загрязнения соседей. Повторить.

```python
from collections import deque

def find_order(num_courses, prerequisites):
    graph = {i: [] for i in range(num_courses)}
    indegree = [0] * num_courses

    for course, prereq in prerequisites:
        graph[prereq].append(course)
        indegree[course] += 1

    queue = deque([i for i in range(num_courses) if indegree[i] == 0])
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            indegree[neighbour] -= 1
            if indegree[neighbour] == 0:
                queue.append(neighbour)

    return order if len(order) == num_courses else []  # empty = cycle exists
```

- **Подводная ошибка**: если в результате меньше узлов, чем в графе, существует цикл (входящая степень некоторых узлов никогда не достигает 0).

## Кратчайшие пути

### Алгоритм Дейкстры

- Находит кратчайшие пути от источника ко всем остальным узлам в графе с **неотрицательным** взвешиванием. Использует приоритетную очередь (min-heap).

```python
import heapq

def dijkstra(graph, start):
    # graph: {node: [(neighbour, weight), ...]}
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    heap = [(0, start)]

    while heap:
        d, node = heapq.heappop(heap)
        if d > dist[node]:
            continue  # stale entry

        for neighbour, weight in graph[node]:
            new_dist = d + weight
            if new_dist < dist[neighbour]:
                dist[neighbour] = new_dist
                heapq.heappush(heap, (new_dist, neighbour))

    return dist
```

- Время: $O((|V| + |E|) \log |V|)$ с двоичной кучей.

- **Подводный камень**: строка `if d > dist[node]: continue` необходима. Без него вы обрабатываете устаревшие записи кучи, что может привести к деградации до $O(|V|^2)$.

- **Подводный камень**: Дейкстра не работает с отрицательными весами. Если ребро имеет отрицательный вес, жадное предположение (как только узел финализирован, его расстояние становится оптимальным) нарушается. Вместо этого используйте Bellman-Ford.

### Сложно: время задержки в сети

- **Задача**: учитывая узлы $n$ и взвешенные направленные ребра, найти время, за которое сигнал достигнет всех узлов от источника. Возвращайте -1, если не все узлы доступны.

```python
def network_delay(times, n, k):
    graph = {i: [] for i in range(1, n + 1)}
    for u, v, w in times:
        graph[u].append((v, w))

    dist = dijkstra(graph, k)
    max_time = max(dist.values())
    return max_time if max_time < float('inf') else -1
```

## Сильно связанные компоненты

- В ориентированном графе **сильно связный компонент (SCC)** — это максимальный набор узлов, где каждый узел может достигать любого другого.

- **Алгоритм Косараджу**: (1) DFS на исходном графе, порядок окончания записи. (2) Транспонировать граф (перевернуть все ребра). (3) DFS на транспонированном графе в обратном порядке. Каждое дерево DFS на шаге 3 представляет собой один SCC.

- **Когда использовать**: поиск циклических зависимостей, 2-SAT, сжатие ориентированного графа в группу DAG из SCC.

## Резюме распространенных ошибок

| ловушка | Пример | Исправить |
|---------|---------|-----|
| Маркировка посещений при удалении из очереди | Один и тот же узел поставлен в очередь несколько раз | Отметить посещение при постановке в очередь |
| Два государства посетили в направленных графах | Не могу отличить заднюю кромку от поперечной | Используйте три состояния: непосещено/в работе/выполнено |
| Дейкстра с отрицательными весами | Неправильные кратчайшие пути | Используйте Bellman-Ford |
| Забыв `if d > dist[node]: continue` | Обработка устаревших записей кучи | Всегда пропускайте, если текущее расстояние хуже |
| Проверка границ сетки | Индекс вне диапазона | `0 <= nr < rows and 0 <= nc < cols` |
| Не считая времени = 0, крайний случай | Гниющие апельсины: свежих апельсинов нет | Проверьте `fresh == 0` перед BFS |
| Построение ориентированного графа как неориентированного | Предпосылки идут в одну сторону | Добавьте край только в одном направлении |
