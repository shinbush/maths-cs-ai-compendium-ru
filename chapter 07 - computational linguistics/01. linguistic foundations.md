# Лингвистические фонды

*Лингвистика предоставляет структурный словарь, который системы НЛП неявно изучают и используют. Этот файл охватывает морфологию, синтаксис, семантику, прагматику, фонологию, анализ избирательных групп и зависимостей, а также гипотезу распределения — науку о человеческом языке, лежащую в основе токенизации, грамматики и значения в ИИ.*

— Прежде чем мы сможем создавать системы, которые понимают или генерируют язык, нам необходимо понять, как работает сам язык. 

- Лингвистика – это научное исследование языка, предоставляющее концептуальный словарь, из которого НЛП постоянно заимствует. 

- Даже современные нейронные модели, которые изучают язык на основе необработанных данных, неявно заново открывают многие структуры, которые лингвисты каталогизировали на протяжении десятилетий.

- Язык имеет структуру на каждом уровне: звуки, из которых состоят слова, части, из которых состоят слова, правила, по которым слова объединяются в предложения, значение, которое эти предложения несут, и то, как контекст влияет на интерпретацию. Мы пройдем каждый уровень снизу вверх.

- **Морфология** — это изучение внутреннего строения слов. Слова не атомарны; они состоят из более мелких значимых единиц, называемых **морфемами**.

- Слово «несчастье» содержит три морфемы: «не-» (приставка, означающая «не»), «счастливый» (корень) и «-ность» (суффикс, превращающий прилагательное в существительное). Каждая морфема вносит свой вклад в значение.

- **корень** (или основа) – это основная морфема, несущая основное значение. «Счастливый», «бегать», «вычислять» — это корни. 

– **Аффикс** – это морфема, которая прикрепляется к корню и изменяет его. 

– В английском языке есть **префиксы** (перед корнем: un-, re-, pre-) и **суффиксы** (после: -ing, -ed, -tion). В некоторых языках также есть инфиксы (вставленные в корень) и циркумфиксы (обтекающие).

![Morpheme tree: "unhappiness" split into prefix "un", root "happy", suffix "ness"](../images/morpheme_tree.svg)

- Существует два вида морфологических процессов. **Флексия** изменяет грамматические свойства слова, не меняя его основного значения или части речи: «бежать» становится «бежит» (третье лицо), «бежит» (прогрессивное), «бежать» (прошедшее время). Это слово по-прежнему является глаголом, означающим то же самое.

- **Происхождение** создает новое слово, часто меняя часть речи: «счастливый» (прилагательное) становится «счастьем» (существительное), «вычислять» (глагол) становится «вычислительным» (существительное) становится «вычислительным» (прилагательное). Каждый вывод меняет значение и грамматическую категорию.

- Языки чрезвычайно различаются по морфологической сложности. Английский относительно **аналитический** (несколько морфем в слове, в зависимости от порядка слов). 

- Турецкий и финский языки **агглютинативны** (слова могут содержать множество связанных вместе морфем). В арабском и иврите используется **шаблонная** морфология (корни представляют собой скелеты согласных, такие как k-t-b для «писать», а образцы гласных вставляются для создания разных слов: китаб «книга», катаба «он написал», мактуб «написанный»).

- Морфология важна для НЛП, поскольку она влияет на токенизацию. Токенизатор на уровне слова рассматривает слова «бег», «бег», «бег» и «бег» как четыре несвязанных символа. 

- Морфологически осведомленная система распознает, что у них общий корень. Токенизация подслов (BPE, WordPiece), которую мы рассмотрим в файле 02, представляет собой статистическую аппроксимацию морфологического анализа.

– **Синтаксис** – это изучение того, как слова объединяются во фразы и предложения. В каждом языке есть правила, регулирующие порядок и структуру слов; их нарушение приводит к тарабарщине. 

- «Кот сидел на коврике» — грамматический английский; «Мат на субботнем коте» — нет.

- Существуют две основные схемы описания синтаксической структуры.

- **Грамматика структуры фраз** (также называемая грамматикой избирательного округа) гласит, что предложения строятся путем вложения фраз внутрь фраз. Предложение (S) состоит из именной группы (NP) и глагольной группы (VP). 

- Существительная группа может быть определителем (Det), за которым следует существительное (N). Глагольная группа может представлять собой глагол (V), за которым следует именное словосочетание. Эти правила строят дерево:

![Constituency tree for "the cat sat on the mat": S branches into NP and VP, NP into Det "the" and N "cat", VP into V "sat" and PP, PP into P "on" and NP](../images/constituency_tree.svg)

- Это дерево называется **деревом избирательного округа** (или деревом разбора). Каждый внутренний узел — это тип фразы, каждый лист — это слово. Дерево отражает иерархическую группировку: «на коврике» — это единица (предложная фраза), «сидеть на коврике» — это единица (глагольная группа), и все это — предложение.- **Бесконтекстная грамматика (CFG)** формализует эти правила. Он состоит из набора правил продукции, каждое из которых имеет форму $A \to \alpha$, где $A$ — нетерминальный символ (тип фразы, например NP или VP), а $\alpha$ — последовательность терминалов (слов) и нетерминалов. Например:

```
S  → NP VP
NP → Det N
NP → Det N PP
VP → V NP
VP → V PP
PP → P NP
Det → "the" | "a"
N  → "cat" | "mat" | "dog"
V  → "sat" | "chased"
P  → "on" | "under"
```

- Начиная с S и неоднократно применяя правила, вы можете генерировать все предложения, которые позволяет грамматика. При синтаксическом анализе происходит обратный процесс: по заданному предложению найдите дерево (или деревья), которое его создало. Предложение с несколькими допустимыми деревьями разбора **синтаксически неоднозначно**. Выражение «Я видел человека в телескоп» имеет два значения: я использовал телескоп, чтобы увидеть человека, или я видел человека, у которого был телескоп.

- **Грамматика зависимостей** использует другую точку зрения. Вместо вложенности фраз он описывает прямые связи между словами. Каждое слово в предложении зависит ровно от одного другого слова (его **головы**), за исключением корня предложения. В результате получается **дерево зависимостей**, ребра которого помечены грамматическими отношениями (субъект, объект, модификатор и т. д.).

![Dependency tree for "the cat sat on the mat": arrows from "sat" to "cat" (nsubj) and to "on" (prep), from "on" to "mat" (pobj), from "cat" to "the" (det), from "mat" to "the" (det)](../images/dependency_tree.svg)

- В представлении зависимости «sat» является корнем. «Кот» зависит от «сат» как субъекта (nsubj). «Он» зависит от «сат» как модификатора предлога. «Мат» зависит от «on» как объекта предлога. Каждое слово свисает ровно с одной головы, образуя дерево.

- Грамматика зависимостей стала доминирующей структурой в современном НЛП, поскольку деревья зависимостей легче создавать с помощью статистических анализаторов, а отношения более непосредственно сопоставляются с семантическими ролями (кто, что и кому сделал).

- **Валентность** описывает, сколько аргументов требуется глаголу. Слово «Сон» **непереходно** (один аргумент: спящий). «Есть» — **переходное** (два: едящий и съеденное). «Дать» **дитранзитив** (три: дающий, данная вещь и получающий). Знание валентности глагола ограничивает допустимость деревьев синтаксического анализа.

- **Семантика** – это изучение значения. Синтаксис сообщает вам, как структурировано предложение; семантика говорит вам, что это значит.

- **Лексическая семантика** касается значения отдельных слов. Слова связаны друг с другом систематическим образом:

    – **Синонимия**: слова с (почти) одинаковым значением. «Большой» и «большой» — синонимы. Настоящая совершенная синонимия встречается редко; почти всегда есть тонкие различия в значении или использовании.
    - **Антонимия**: слова с противоположным значением. «Горячее» и «холодное», «купить» и «продать».
    - **Гиперонимия/гипонимия**: отношения «есть-а». «Собака» — гипоним слова «животное» (собака — вид животного). «Животное» — это гиперним слова «собака». Они образуют таксономические иерархии.
    - **Меронимия**: отношения «части». «Колесо» — это мероним слова «автомобиль».
    – **Полисемия**: одно слово имеет несколько связанных значений. «Банк» означает финансовое учреждение или берег реки. Контекст устраняет неоднозначность.

- **Устранение неоднозначности смысла слова (WSD)** — это задача определения того, какой смысл многозначного слова имеется в виду в данном контексте. В фразе «Я положил деньги в банк» финансовый смысл верен. В «Мы сидели на берегу реки» географический смысл есть. WSD был центральной проблемой раннего НЛП; современные контекстные встраивания (ELMo, BERT) в значительной степени решают эту проблему, создавая разные векторные представления для разных использований одного и того же слова.

– **Композиционная семантика** изучает, как значения отдельных слов объединяются, образуя значение фразы или предложения. Принцип **композиционности** (приписываемый Фреге) гласит, что значение сложного выражения определяется значениями его частей и правилами их объединения. «Кошка преследовала собаку» означает нечто иное, чем «собака преследовала кошку», поскольку синтаксическая структура (кто является субъектом или объектом) взаимодействует со значениями слов.

- Не всякий смысл композиционен. **Идиомы**, такие как «Kick the Bucket» (что означает «умереть»), имеют значения, которые невозможно вывести из их частей. Это вызов любому композиционному подходу.- **Распределительная семантика** — это вычислительный подход к определению значения, лежащий в основе современного НЛП. **Гипотеза распределения** (Ферт, 1957) гласит: «Вы узнаете слово по тому, в какой компании оно находится». Слова, встречающиеся в схожих контекстах, обычно имеют схожие значения. Это теоретическая основа встраивания слов (Word2Vec, GloVe), которую мы рассмотрим в файле 03.

- **Прагматика** изучает, как контекст влияет на значение. Одно и то же предложение может означать разные вещи в зависимости от того, кто его произнес, когда, где и почему.

- «Можете ли вы передать соль?» синтаксически представляет собой вопрос «да/нет» о способностях. С прагматической точки зрения это просьба. Вы бы не ответили «Да, могу» и потом сидели бы на месте. Понимание этого требует знаний, выходящих за рамки буквальных слов, в частности, условностей **речевых актов**.

- **Теория речевого акта** (Остин, Серл) различает:
    - **Локутивный акт**: буквальное содержание («Можете ли вы передать соль?»)
    - **Иллокутивный акт**: предполагаемая функция (просьба)
    - **Перлокутивный акт**: воздействие на слушателя (передают соль)

- **Импликатура** (Грайс) означает, что подразумевается, но не заявлено явно. Если кто-то спросит: «Джон хорошо готовит?» и вы отвечаете: «Он британец», вы не ответили на вопрос буквально, но слушатель может сделать вывод (через культурные стереотипы, справедливо или нет), что вы имеете в виду «нет». **Принцип сотрудничества** Грайса гласит, что говорящие обычно стараются быть информативными, правдивыми, актуальными и ясными, а слушатели интерпретируют высказывания, предполагая, что эти принципы соблюдаются.

- **Кореференция** — это прагматическое явление, когда разные выражения относятся к одному и тому же объекту. В «Алиса пошла в магазин. Она купила молоко» «она» относится к Алисе. Разрешение кореференции необходимо для понимания текста, состоящего из нескольких предложений, и является ключевой задачей НЛП.

– **Структура дискурса** описывает, как предложения соединяются, образуя связный текст. Повествование имеет начало, середину и конец. Аргумент имеет утверждения и доказательства. **Теория риторической структуры (RST)** анализирует текст как дерево дискурсивных отношений (развитие, контраст, причина и т. д.) между сегментами.

- Прагматика — это то, где НЛП становится сложнее всего. Современные языковые модели обрабатывают большую часть синтаксиса и семантики неявно посредством обучающих данных, но прагматическое рассуждение, понимание сарказма, импликатуры и контекстно-зависимого значения остается пограничной проблемой.

- **Фонология** изучает звуковые системы языков. Хотя эта глава посвящена тексту, краткий обзор переходит к главе, посвященной аудио и речи (глава 09).

- **фонема** – это наименьшая звуковая единица, определяющая значение. В английском языке около 44 фонем. Слова «летучая мышь» и «пат» различаются одной фонемой (/b/ vs /p/), что полностью меняет смысл. Это называется **минимальной парой**.

- **Аллофоны** — это разные физические реализации одной и той же фонемы, не меняющие значения. «p» в «pin» (с придыханием, с подачей воздуха) и «p» в «spin» (без наддува) являются аллофонами /p/ в английском языке; носитель языка воспринимает их как один и тот же звук.

- **Международный фонетический алфавит (IPA)** обеспечивает стандартизированное обозначение фонем во всех языках. Слово «кот» транскрибируется как /kæt/. IPA — это мост между письменным текстом и речевыми системами.

- **Просодия** охватывает ритм, ударение и интонацию речи. «Я не говорил, что он украл деньги» имеет семь разных значений в зависимости от того, на каком слове делается ударение. Просодия несет информацию, которую теряет сам текст, поэтому системы преобразования текста в речь должны тщательно ее моделировать.

- В НЛП фонологические знания проявляются в преобразовании текста в речь (преобразование графем в фонемы), распознавании речи (сопоставлении акустических сигналов с фонемами) и даже в исправлении орфографии и транслитерации.

1. Создайте простой морфологический анализатор, который разбивает английские слова на вероятные морфемы, используя список общих префиксов и суффиксов.
```python
prefixes = ['un', 're', 'pre', 'dis', 'mis', 'over', 'under', 'out', 'non']
suffixes = ['ing', 'ed', 'ly', 'ness', 'ment', 'tion', 'able', 'ible', 'er', 'est', 'ful', 'less', 'ous']

def analyse_morphemes(word):
    """Simple morpheme analysis using known affixes."""
    parts = []
    remaining = word.lower()

    # Check prefixes
    for p in sorted(prefixes, key=len, reverse=True):
        if remaining.startswith(p) and len(remaining) > len(p) + 2:
            parts.append(f"[prefix: {p}]")
            remaining = remaining[len(p):]
            break

    # Check suffixes
    for s in sorted(suffixes, key=len, reverse=True):
        if remaining.endswith(s) and len(remaining) > len(s) + 2:
            root = remaining[:-len(s)]
            parts.append(f"[root: {root}]")
            parts.append(f"[suffix: {s}]")
            remaining = None
            break

    if remaining is not None:
        parts.append(f"[root: {remaining}]")

    return parts

for word in ['unhappiness', 'reusable', 'disconnected', 'overreacting', 'kindness']:
    print(f"{word:20s} → {' + '.join(analyse_morphemes(word))}")
```

2. Реализуйте простой контекстно-свободный анализатор грамматики, используя рекурсивный спуск. Определите небольшую грамматику и разберите предложение в дереве округов.
```python
class CFGParser:
    """Recursive descent parser for a tiny English grammar."""
    def __init__(self, tokens):
        self.tokens = tokens
        self.pos = 0

    def peek(self):
        return self.tokens[self.pos] if self.pos < len(self.tokens) else None

    def consume(self, expected=None):
        tok = self.peek()
        if expected and tok != expected:
            return None
        self.pos += 1
        return tok

    def parse_det(self):
        if self.peek() in ('the', 'a'):
            return ('Det', self.consume())
        return None

    def parse_noun(self):
        if self.peek() in ('cat', 'dog', 'mat', 'man'):
            return ('N', self.consume())
        return None

    def parse_verb(self):
        if self.peek() in ('sat', 'chased', 'saw'):
            return ('V', self.consume())
        return None

    def parse_prep(self):
        if self.peek() in ('on', 'under', 'with'):
            return ('P', self.consume())
        return None

    def parse_np(self):
        save = self.pos
        det = self.parse_det()
        noun = self.parse_noun()
        if det and noun:
            # Check for optional PP
            pp = self.parse_pp()
            if pp:
                return ('NP', det, noun, pp)
            return ('NP', det, noun)
        self.pos = save
        return None

    def parse_pp(self):
        save = self.pos
        prep = self.parse_prep()
        np = self.parse_np()
        if prep and np:
            return ('PP', prep, np)
        self.pos = save
        return None

    def parse_vp(self):
        save = self.pos
        verb = self.parse_verb()
        if verb:
            np = self.parse_np()
            if np:
                return ('VP', verb, np)
            pp = self.parse_pp()
            if pp:
                return ('VP', verb, pp)
        self.pos = save
        return None

    def parse_sentence(self):
        np = self.parse_np()
        vp = self.parse_vp()
        if np and vp and self.pos == len(self.tokens):
            return ('S', np, vp)
        return None

def print_tree(tree, indent=0):
    if isinstance(tree, str):
        print(' ' * indent + tree)
    elif isinstance(tree, tuple):
        print(' ' * indent + tree[0])
        for child in tree[1:]:
            print_tree(child, indent + 2)

sentences = [
    "the cat sat on the mat",

relations = {
    ('big', 'large'): 'synonym',
    ('big', 'small'): 'antonym',
    ('small', 'tiny'): 'synonym',
    ('dog', 'animal'): 'hypernym',
    ('cat', 'animal'): 'hypernym',
    ('puppy', 'dog'): 'hypernym',
    ('happy', 'glad'): 'synonym',
    ('happy', 'sad'): 'antonym',
    ('hot', 'cold'): 'antonym',
    ('hot', 'warm'): 'synonym',
}

# Build adjacency list
from collections import defaultdict, deque

graph = defaultdict(list)
for (w1, w2), rel in relations.items():
    graph[w1].append((w2, rel))
    graph[w2].append((w1, rel))

def find_path(start, end):
    """BFS to find a path between two words through the relation graph."""
    queue = deque([(start, [(start, None)])])
    visited = {start}
    while queue:
        node, path = queue.popleft()
        if node == end:
            return path
        for neighbor, rel in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [(neighbor, rel)]))
    return None

pairs = [('big', 'tiny'), ('puppy', 'cat'), ('happy', 'sad')]
for w1, w2 in pairs:
    path = find_path(w1, w2)
    if path:
        steps = " → ".join(f"{w}({r})" if r else w for w, r in path)
        print(f"{w1} → {w2}: {steps}")
    else:
        print(f"{w1} → {w2}: no path found")
