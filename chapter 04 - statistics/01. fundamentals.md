# Основы статистики

*Статистика предоставляет язык для описания данных и количественной оценки неопределенности. В этом файле описаны распределения, случайные переменные, PMF, PDF, CDF, ожидание, дисперсия, моменты и центральная предельная теорема — концепции, лежащие в основе каждой метрики оценки ML и функции потерь.*

- Статистика – это наука об обучении на основе данных. Вы собираете наблюдения, обобщаете их и делаете выводы, часто о вещах, которые вы не можете измерить напрямую.

- Представьте, что вы хотите узнать средний рост каждого взрослого человека в стране. Вы не можете измерить всех, поэтому вы измеряете выборку и используете статистику, чтобы сделать обоснованное предположение обо всей совокупности.

- Есть два основных направления:
    - **Описательная статистика**: обобщение уже имеющихся у вас данных (средние значения, диаграммы, таблицы).
    – **Инференциальная статистика**: использование выборки для утверждения о более крупной группе.

– Основой статистики является **распределение**, описание того, как распределяются значения. Все остальное, средние значения, тесты, прогнозы, вытекает из понимания распределений.

– **Распределение частот** подсчитывает, как часто каждое значение (или диапазон значений) появляется в ваших данных. Подумайте о том, чтобы рассортировать результаты экзаменов по ячейкам и подсчитать, сколько студентов попадает в каждую корзину. Результатом является гистограмма.

– **Распределение вероятностей** заменяет необработанные значения вероятностями. Вместо «12 студентов набрали от 70 до 80» говорится: «Вероятность набрать от 70 до 80 составляет 0,24». Столбцы гистограммы превращаются в плавную кривую, если данные непрерывны.

![Frequency distribution as a histogram vs probability distribution as a smooth curve](../images/distribution_types.svg)

- Гистограмма слева построена на основе собранных вами фактических данных. Гладкая кривая справа — это математическая модель, описывающая закономерности данных. Одно эмпирическое, другое теоретическое.

- Чтобы работать с распределениями математически, нам нужен способ присваивать числа результатам. Именно это и делает **случайная величина**.

— Случайная величина — это функция, которая сопоставляет каждый результат эксперимента с действительным числом. Подбросьте монету: результат — «орёл» или «решка», но случайная величина $X$ преобразует его в $X(\text{heads}) = 1$ и $X(\text{tails}) = 0$. Теперь мы можем заняться арифметикой.

![Random variable mapping outcomes (coin, die) to a number line](../images/random_variable.svg)

- **Дискретная** случайная величина принимает счетный набор значений: количество выпавших орлов при 10 бросках, бросок игральной кости, количество электронных писем, которые вы получаете за час.

- **непрерывная** случайная величина может принимать любое значение в интервале: ваш точный рост, время до прибытия следующего автобуса, температуру в полдень.

- Это различие имеет значение, поскольку оно меняет способ расчета вероятностей. Для дискретных переменных суммируем. Для непрерывных переменных проводим интегрирование (вспомним интегралы из главы 3).

- Для дискретной случайной величины **функция массы вероятности (PMF)** дает вероятность каждого конкретного значения:

$$P(X = x) = p(x), \quad \text{where } \sum_{x} p(x) = 1$$

- Для непрерывной случайной величины **функция плотности вероятности (PDF)** дает вероятность попадания в определенный диапазон. Вероятность любого единственного точного значения равна нулю; только интервалы имеют положительную вероятность:

$$P(a \le X \le b) = \int_a^b f(x)\, dx, \quad \text{where } \int_{-\infty}^{\infty} f(x)\, dx = 1$$

- Теперь, когда мы можем присваивать результатам результаты, наиболее естественный вопрос: какую ценность мы ожидаем в среднем?

- **Ожидание** (или ожидаемое значение) – это средневзвешенное значение всех возможных значений, где веса — это вероятности. Думайте об этом как о «центре тяжести» распределения.

- Если вы бросаете честную игральную кость много раз, ваш средний результат приблизится к 3,5. Это ожидаемое значение, хотя на самом деле вы никогда не сможете выбросить 3,5.

- Для дискретной случайной величины:

$$E[X] = \sum_{x} x \cdot p(x)$$

- Для непрерывной случайной величины (с использованием интеграла из главы 3):

$$E[X] = \int_{-\infty}^{\infty} x \cdot f(x)\, dx$$

- Пример: правильный шестигранный кубик имеет $p(x) = 1/6$ для $x = 1, 2, 3, 4, 5, 6$.

$$E[X] = 1 \cdot \tfrac{1}{6} + 2 \cdot \tfrac{1}{6} + 3 \cdot \tfrac{1}{6} + 4 \cdot \tfrac{1}{6} + 5 \cdot \tfrac{1}{6} + 6 \cdot \tfrac{1}{6} = \frac{21}{6} = 3.5$$

- Ожидание линейно, что означает $E[aX + b] = aE[X] + b$. Это свойство чрезвычайно полезно и постоянно проявляется в функциях потерь ML.

- Ожидание указывает нам на центр, но ничего не говорит о том, насколько разбросаны ценности. Чтобы описать полную форму распределения, нам нужны **моменты**.- Мгновение – это ожидание силы $X$. $k$-й **сырой момент**:

$$\mu_k' = E[X^k]$$

- Первый сырой момент ($k = 1$) просто средний: $\mu_1' = E[X] = \mu$.

- Сырые моменты отсчитываются от нуля. Вместо этого нас часто заботит отклонение от среднего значения. $k$-й **центральный момент** центрирует измерение:

$$\mu_k = E[(X - \mu)^k]$$

- Первый центральный момент всегда равен нулю (отклонения выше и ниже среднего отменяются). Второй центральный момент — это **вариативность**.

- Чтобы сравнить распределения в разных масштабах, мы **стандартизируем** путем деления на соответствующую степень стандартного отклонения $\sigma$:

$$\tilde{\mu}_k = \frac{\mu_k}{\sigma^k}$$

- Каждый момент отражает отдельный аспект формы распределения:

![Bell curve annotated with what each moment captures: mean (centre), variance (spread), skewness (asymmetry), kurtosis (tail weight)](../images/moments_shape.svg)

- **1-й момент (среднее)**: где сосредоточено распределение. Точка баланса.
- **2-й момент (дисперсия)**: насколько разбросаны значения вокруг среднего значения. Более высокая дисперсия означает более широкую.
- **3-й момент (Асимметрия)**: наклоняется ли распределение влево или вправо. Нулевая асимметрия означает симметричность.
- **4-й момент (Куртосис)**: Насколько тяжелы хвосты. Более высокий эксцесс означает больше экстремальных выбросов.

— Проработаем все четыре момента для конкретного набора данных: $X = \{2, 4, 4, 4, 5, 5, 7, 9\}$.

- **Шаг 1: Среднее** (первый исходный момент)

$$\mu = \frac{2 + 4 + 4 + 4 + 5 + 5 + 7 + 9}{8} = \frac{40}{8} = 5$$

- **Шаг 2: Отклонение** (2-й центральный момент). Вычтите среднее значение из каждого значения, возведите в квадрат, затем усредните:

$$\sigma^2 = \frac{(2{-}5)^2 + (4{-}5)^2 + (4{-}5)^2 + (4{-}5)^2 + (5{-}5)^2 + (5{-}5)^2 + (7{-}5)^2 + (9{-}5)^2}{8}$$

$$= \frac{9 + 1 + 1 + 1 + 0 + 0 + 4 + 16}{8} = \frac{32}{8} = 4$$

– **Стандартное отклонение** — $\sigma = \sqrt{4} = 2$.

- **Шаг 3: Асимметрия** (стандартизированный третий центральный момент). Возведите в куб отклонения, среднее значение, разделите на $\sigma^3$:

$$\tilde{\mu}_3 = \frac{1}{8} \cdot \frac{(-3)^3 + (-1)^3 + (-1)^3 + (-1)^3 + 0^3 + 0^3 + 2^3 + 4^3}{2^3}$$

$$= \frac{1}{8} \cdot \frac{-27 -1 -1 -1 + 0 + 0 + 8 + 64}{8} = \frac{42}{64} = 0.656$$

- Положительная асимметрия означает, что правый хвост длиннее, что имеет смысл, поскольку 9 намного выше среднего.

- **Шаг 4: Куртозис** (стандартизированный 4-й центральный момент). Возведем отклонения в 4-ю степень:

$$\tilde{\mu}_4 = \frac{1}{8} \cdot \frac{(-3)^4 + (-1)^4 + (-1)^4 + (-1)^4 + 0^4 + 0^4 + 2^4 + 4^4}{2^4}$$

$$= \frac{1}{8} \cdot \frac{81 + 1 + 1 + 1 + 0 + 0 + 16 + 256}{16} = \frac{356}{128} = 2.781$$

- Нормальное распределение имеет эксцесс, равный 3 (так называемый «мезокуртический»). Наше значение 2,781 близко, что позволяет предположить, что хвосты примерно нормальные. Значения выше 3 («лептокуртические») сигнализируют о более тяжелых хвостах; ниже 3 («платыкуртик») сигнализируют более светлые хвосты. Некоторые формулы сообщают о **избыточном эксцессе** путем вычитания 3, поэтому наш избыточный эксцесс будет равен $-0.219$.

## Задачи по кодированию (используйте CoLab или блокнот)

1. Вычислите ожидаемое значение игральной кости, где грани 6 имеют вероятность 0,3, а все остальные грани делят оставшуюся вероятность поровну. Проверьте, смоделировав 100 000 бросков.
```python
import jax
import jax.numpy as jnp

# Loaded die: face 6 has p=0.3, others share 0.7 equally
probs = jnp.array([0.14, 0.14, 0.14, 0.14, 0.14, 0.30])
faces = jnp.array([1, 2, 3, 4, 5, 6])

# Analytical expected value
ev = jnp.sum(faces * probs)
print(f"Expected value (formula): {ev:.4f}")

# Simulation
key = jax.random.PRNGKey(42)
rolls = jax.random.choice(key, faces, shape=(100_000,), p=probs)
print(f"Expected value (simulation): {rolls.mean():.4f}")
```

2. Вычислите все четыре момента (среднее значение, дисперсию, асимметрию, эксцесс) для набора данных из рабочего примера, затем измените данные и наблюдайте, как меняется каждый момент.
```python
import jax.numpy as jnp

x = jnp.array([2, 4, 4, 4, 5, 5, 7, 9], dtype=jnp.float32)

mean = jnp.mean(x)
variance = jnp.mean((x - mean) ** 2)
std = jnp.sqrt(variance)
skewness = jnp.mean(((x - mean) / std) ** 3)
kurtosis = jnp.mean(((x - mean) / std) ** 4)

print(f"Mean:     {mean:.3f}")
print(f"Variance: {variance:.3f}")
print(f"Std Dev:  {std:.3f}")
print(f"Skewness: {skewness:.3f}")
print(f"Kurtosis: {kurtosis:.3f}")
print(f"Excess K: {kurtosis - 3:.3f}")
```

3. Визуализируйте PMF и CDF рядом, чтобы бросок кубика был справедливым. Попробуйте изменить вероятности, чтобы увидеть, как меняются фигуры.
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

faces = jnp.array([1, 2, 3, 4, 5, 6])
pmf = jnp.ones(6) / 6  # fair die; try changing these!
cdf = jnp.cumsum(pmf)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))

ax1.bar(faces, pmf, color="#3498db", alpha=0.8)
ax1.set_title("PMF")
ax1.set_xlabel("Face")
ax1.set_ylabel("P(X = x)")
ax1.set_ylim(0, 0.5)

ax2.step(faces, cdf, where="mid", color="#e74c3c", linewidth=2)
ax2.set_title("CDF")
ax2.set_xlabel("Face")
ax2.set_ylabel("P(X ≤ x)")
ax2.set_ylim(0, 1.1)

plt.tight_layout()
plt.show()
```
