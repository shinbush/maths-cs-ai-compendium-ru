# ИИ для биологии

- Прогнозирование структуры белка: AlphaFold 1/2/3, ESMFold, коэволюционный анализ, преобразователи MSA.
- Дизайн белка: обратное сворачивание (ProteinMPNN), диффузия для генерации белка (RFDiffusion), галлюцинации.
- Открытие лекарств: молекулярные представления (УЛЫБКИ, графики), предсказание молекулярных свойств, виртуальный скрининг, стыковка.
- Генеративная химия: молекулярная генерация (ВАЭ, ГАН, диффузия), прогнозирование ретросинтеза.
- Геномика: моделирование последовательностей ДНК (энформер, ДНК гиены), прогнозирование вариантов эффектов, разработка руководства CRISPR.
- Анализ отдельных клеток: scRNA-seq, кластеризация типов клеток, определение траектории
- Медицинская визуализация: радиология (CheXNet), патология (полные изображения), сегментация (nnU-Net)
- Клиническое НЛП: извлечение медицинских объектов, сопоставление клинических исследований, электронные медицинские записи.
