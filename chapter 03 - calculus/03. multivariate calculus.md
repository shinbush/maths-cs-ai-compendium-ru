# Многомерное исчисление

*Многомерное исчисление расширяет производные и интегралы до функций многих переменных, что очень важно, поскольку модели ML имеют миллионы параметров. В этом файле описаны частные производные, градиенты, якобиан, гессиан и правило цепочки многих переменных, которое делает возможным обратное распространение ошибки.*

- До сих пор наши функции принимали один входной сигнал $x$ и создавали один выходной $f(x)$. Но в ML мы почти никогда не работаем только с одной переменной. 

— Рассмотрим функцию двух переменных, например $f(x, y) = x^2 + y^2$. Это определяет поверхность в трехмерном пространстве, форму чаши. Мы хотим знать: если мы немного подтолкнем $x$, оставив $y$ фиксированным, как изменится $f$? Это **частная производная**.

- **Частная производная** от $f$ относительно $x$, записанная $\frac{\partial f}{\partial x}$, рассматривает все остальные переменные как константы и нормально дифференцируется относительно $x$.

- Для $f(x, y) = x^2y + 3x - 2y$:

$$\frac{\partial f}{\partial x} = 2xy + 3 \qquad \frac{\partial f}{\partial y} = x^2 - 2$$

- Чтобы вычислить $\frac{\partial f}{\partial x}$, мы рассматривали $y$ как константу, поэтому $x^2y$ дифференцировался до $2xy$, $3x$ до $3$ и От $-2y$ до $0$. 

- Чтобы вычислить $\frac{\partial f}{\partial y}$, мы рассматривали $x$ как константу, поэтому $x^2y$ дифференцировался до $x^2$, $3x$ до $0$ и От $-2y$ до $-2$.

- Геометрически получение частной производной по $x$ похоже на разрезание 3D-поверхности плоскостью, параллельной плоскости $xz$ (при фиксированном значении $y$), и определение наклона результирующей кривой.

![Partial derivative: slice the surface by holding one variable constant](../images/partial_derivative.svg)

– **Градиент** объединяет все частные производные в один вектор:

$$\nabla f = \left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n}\right)$$

- Для $f(x, y) = x^2 + y^2$: $\nabla f(x, y) = (2x, 2y)$. В точке $(1, 2)$: $\nabla f(1, 2) = (2, 4)$.

- Градиент имеет два ключевых свойства:

    - **Направление**: указывает в направлении наибольшего увеличения. Представьте себе путешественника на горе. Уклон в их положении направлен прямо вверх по самой крутой тропе.

    - **Величина**: $\|\nabla f\|$ указывает скорость увеличения в самом крутом направлении. Большой уклон означает, что местность крутая; небольшой градиент означает, что он почти плоский.

![Gradient vectors point uphill, perpendicular to contour lines](../images/gradient_contour.svg)

- Поскольку уклон направлен вверх, движение в противоположном направлении ($-\nabla f$) идет вниз, в сторону более низких значений. Эта простая идея лежит в основе **градиентного спуска** — метода оптимизации, который мы подробно рассмотрим в последующих главах. На данный момент ключевым выводом является то, что градиент говорит вам, в каком направлении находится «вверх» и насколько крут подъем.

- **Производная по направлению** обобщает частные производные. Вместо вопроса «как изменяется $f$ вдоль оси $x$?», он спрашивает: «Как $f$ изменяется в любом направлении $\mathbf{u}$?» Он вычисляется как скалярное произведение градиента на единичный вектор:

$$D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$$

- Для $f(x, y) = x^2 + y^2$ по адресу $(1, 2)$ в направлении $\mathbf{v} = (3, 4)$: сначала выполните нормализацию, чтобы получить $\mathbf{u} = (3/5, 4/5)$, затем $D_{\mathbf{u}} f = (2, 4) \cdot (3/5, 4/5) = 6/5 + 16/5 = 22/5$.

- Частные производные — это особые случаи производных по направлению, когда направление совпадает с осью координат. Если производная по направлению равна нулю в каком-то направлении, функция в этой точке плоская в этом направлении.

- **Контурные линии** (или кривые уровня) соединяют точки, в которых функция имеет одинаковое значение. Для $f(x, y) = x^2 + y^2$ контурные линии представляют собой круги с центром в начале координат: $x^2 + y^2 = c$ для разных значений $c$.

- Контурные линии никогда не пересекают друг друга (точка не может иметь два разных значения функции). 

- Градиент всегда перпендикулярен контурным линиям, указывая от меньших значений к более высоким. 

- Близко расположенные контурные линии указывают на крутой рельеф; широко расставленные линии указывают на пологие склоны.- До сих пор наши функции выдавали один результат. Но многие функции выдают несколько результатов. Функция $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ принимает входные данные $n$ и создает выходные данные $m$. **Матрица Якобиана** упорядочивает все частные производные такой вектор-функции:

```math
J = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}
```

- Каждая строка якобиана представляет собой градиент одного выходного компонента. Для функции с 3 входами и 2 выходами якобиан представляет собой матрицу $2 \times 3$.

- Якобиан обобщает производную на векторные функции. 

- Точно так же, как производная скалярной функции показывает, насколько изменяется выходной сигнал на единицу изменения входных данных, якобиан показывает, как каждый выходной сигнал изменяется по отношению к каждому входному сигналу.

- **Определитель якобиана** измеряет, насколько преобразование локально растягивает или сжимает пространство. 

- Если определитель равен 2, площадь небольших регионов удваивается. Если он равен 0, преобразование сжимает пространство до более низкого измерения (вспомните из нашей главы о матрицах, что нулевой определитель означает сингулярное, необратимое преобразование).

- Когда составлено несколько преобразований (одно из которых перетекает в другое), якобиан общего отображения является продуктом отдельных якобианов. В последующих главах мы увидим, что эта идея станет центральной.

- Там, где градиент фиксирует информацию первого порядка (наклоны), **матрица Гессиана** фиксирует информацию второго порядка (кривизна). 

- Для скалярной функции $f(x_1, \ldots, x_n)$ гессиан представляет собой матрицу $n \times n$ всех вторых частных производных:

```math
H = \begin{bmatrix} \frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots \\ \frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \cdots \\ \vdots & \vdots & \ddots \end{bmatrix}
```

- Для $f(x, y) = x^3 + 2xy^2 - y^3$ градиент равен $(3x^2 + 2y^2,\; 4xy - 3y^2)$, а гессиан:

```math
H = \begin{bmatrix} 6x & 4y \\ 4y & 4x - 6y \end{bmatrix}
```

- Диагональные записи ($6x$ и $4x - 6y$) сообщают вам, как изменяется наклон в направлении $x$ при движении в $x$, и аналогично для $y$. 

- Внедиагональные записи ($4y$) сообщают вам, как изменяется наклон в одном направлении при движении в другом направлении.

- **Теорема Клеро** гарантирует, что для функций с непрерывными вторыми производными смешанные частные производные равны: $\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}$. 

- Это означает, что гессиан симметричен, что (как мы видели в главе о матрицах) гарантирует действительные собственные значения и ортогональные собственные векторы.

- Гессиан говорит нам о форме функции вблизи критической точки (где градиент равен нулю):

    - Если $H$ положительно определен (все собственные значения положительны), точка является **локальным минимумом**, поверхность изгибается вверх во всех направлениях, как чаша.
    - Если $H$ отрицательно определен (все собственные значения отрицательны), точка является **локальным максимумом**, поверхность изгибается вниз, как перевернутая чаша.
    - Если $H$ имеет как положительные, так и отрицательные собственные значения, точка является **седловой точкой**, поверхность изгибается вверх в одних направлениях и вниз в других, как горный перевал.

- **Правило многомерной цепочки** расширяет правило цепочки на функции нескольких переменных. Если $z = f(x, y)$ где $x = g(t)$ и $y = h(t)$, то:

$$\frac{dz}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt}$$

- Каждый путь от $t$ до $z$ вносит член: частная производная по этому пути, умноженная на производную промежуточной переменной относительно $t$. 

- Например, если $z = x^2 y + 3x - y^2$, $x = \cos(t)$, $y = \sin(t)$:

$$\frac{dz}{dt} = (2xy + 3)(-\sin t) + (x^2 - 2y)(\cos t)$$

- Помимо вычисления производных вручную, существует три подхода:

    - **Числовое дифференцирование**: приблизительное $f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}$ для маленьких $h$. Просто, но шумно и неточно.
    - **Символическое дифференцирование**: алгебраически применяйте правила дифференцирования для получения точной формулы. Может создавать выражения, которые растут экспоненциально.
    - **Автоматическое дифференцирование (autodiff)**: отслеживает цепочку операций и эффективно вычисляет точные производные. Это то, что используют JAX, PyTorch и TensorFlow. Он дает точные числовые значения (не приблизительные) без создания раздутых символических выражений.

3. Вычислите гессиан $f(x, y) = x^3 + 2xy^2 - y^3$, используя `jax.hessian`, и убедитесь, что он симметричен.
```python
import jax
import jax.numpy as jnp

def f(xy):
    x, y = xy[0], xy[1]
    return x**3 + 2*x*y**2 - y**3

H = jax.hessian(f)
point = jnp.array([1.0, 2.0])
hess = H(point)
print(f"Hessian:\n{hess}")
print(f"Symmetric: {jnp.allclose(hess, hess.T)}")
# Expected: [[6x, 4y], [4y, 4x-6y]] = [[6, 8], [8, -8]]
```

4. Создайте минимальный движок автодифференциала с нуля. 
    - Каждый `Var` отслеживает свое значение и способы распространения градиентов назад по правилу цепочки. 
    - Попробуйте расширить его, добавив больше операций (деление, власть и т. д.).
    — Это основа того, как были разработаны JAX, PyTorch и Numpy. 
```python
class Var:
    def __init__(self, val, children=(), backward_fn=None):
        self.val = val
        self.grad = 0.0
        self.children = children
        self.backward_fn = backward_fn

    def __add__(self, other):
        out = Var(self.val + other.val, children=(self, other))
        def _backward():
            self.grad += out.grad    # d(a+b)/da = 1
            other.grad += out.grad   # d(a+b)/db = 1
        out.backward_fn = _backward
        return out

    def __mul__(self, other):
        out = Var(self.val * other.val, children=(self, other))
        def _backward():
            self.grad += other.val * out.grad  # d(a*b)/da = b
            other.grad += self.val * out.grad  # d(a*b)/db = a
        out.backward_fn = _backward
        return out

    def backward(self):
        # topological sort then propagate gradients
        # we will go through this in data structures and algorithms
        order, visited = [], set()
        def topo(v):
            if v not in visited:
                visited.add(v)
                for c in v.children:
                    topo(c)
                order.append(v)
        topo(self)
        self.grad = 1.0
        for v in reversed(order):
            if v.backward_fn:
                v.backward_fn()

# f(x, y) = x*x*y + x  at (3, 2)
x = Var(3.0)
y = Var(2.0)
f = x * x * y + x       # = 3*3*2 + 3 = 21

f.backward()
print(f"f = {f.val}")           # 21.0
print(f"df/dx = {x.grad}")     # 2*x*y + 1 = 13.0
print(f"df/dy = {y.grad}")     # x*x = 9.0
```
