# Обнаружение и сегментация объектов

*Обнаружение объектов локализует и классифицирует каждый объект на изображении; сегментация присваивает метку каждому пикселю. В этом файле описаны IoU, mAP, поля привязки, семейство R-CNN, YOLO, SSD, сети Feature Pyramid Networks, семантическая/экземплярная/паноптическая сегментация (U-Net, Mask R-CNN, SAM), а также метрики, которые их сравнивают.*

- Классификация изображений (файл 02) отвечает на вопрос «что на этом изображении?» Обнаружение объектов задает более сложный вопрос: «Какие объекты находятся на этом изображении и где они?» 

- Сегментация идет еще дальше: «какие пиксели принадлежат какому объекту или категории?» Эти задачи образуют иерархию все более точного пространственного понимания.

– Модель **обнаружения объектов** выводит набор **ограничивающих рамок**, каждая из которых определяется четырьмя координатами (верхний левый угол $x, y$, ширина, высота) и меткой класса с показателем достоверности. Одно изображение может содержать ноль, один или сотни объектов из нескольких классов.

![Input image with multiple objects, each enclosed by a coloured bounding box with a class label and confidence score](../images/detection_boxes.svg)

- **Пересечение через объединение (IoU)** измеряет, насколько хорошо прогнозируемая ограничивающая рамка соответствует основной истине. Это область перекрытия, разделенная на область объединения:

$$\text{IoU} = \frac{\text{Area of Intersection}}{\text{Area of Union}}$$

- IoU, равный 1, означает идеальное перекрытие; IoU, равный 0, означает полное отсутствие перекрытия. Стандартный порог «правильного» обнаружения — IoU $\geq 0.5$, хотя используются и более строгие пороги (0,75, 0,9).

- Обнаружение считается **истинно положительным (TP)**, если его IoU с основным блоком истинности превышает пороговое значение и класс правильный. 

- **ложное срабатывание (FP)** — это предсказанный блок, который не соответствует какой-либо основной истине. 

- **Ложноотрицательный результат (FN)** — это объект истинной истины, которому не соответствует ни один прогноз. Это те же концепции точности/отзыва из главы 06.

- **Средняя точность (AP)** суммирует качество обнаружения для одного класса. Для каждого класса ранжируйте все обнаружения по показателю достоверности, вычислите точность и полноту для каждого ранга, а также вычислите площадь под кривой точности и полноты:

$$\text{AP} = \int_0^1 p(r) \, dr$$

- На практике кривая интерполируется: на каждом уровне отзыва устанавливается максимальная точность при любом вызове $\geq r$. Это сглаживает кривую и делает ее монотонно убывающей.

- **Средняя средняя точность (mAP)** усредняет AP по всем классам. «mAP@0,5» использует порог IoU 0,5. «mAP@[.5:.95]» (стандарт COCO) усредняет mAP по десяти пороговым значениям IoU от 0,5 до 0,95 с шагом 0,05, что обеспечивает как обнаружение, так и точную локализацию.

- **Немаксимальное подавление (NMS)** удаляет повторяющиеся обнаружения. Когда модель прогнозирует несколько перекрывающихся блоков для одного и того же объекта, NMS сохраняет блок с наивысшей степенью достоверности и удаляет все остальные, которые перекрываются с ним выше порога IoU. Это применяется для каждого класса после того, как модель выдает необработанные прогнозы.

- **Двухэтапные детекторы** сначала предлагают регионы-кандидаты, затем классифицируют и уточняют каждое предложение.

- **R-CNN** (Girshick et al., 2014) был первым успешным детектором глубокого обучения. Он использует выборочный поиск (классический алгоритм), чтобы предложить около 2000 регионов-кандидатов, деформирует каждый регион до фиксированного размера, независимо пропускает каждый регион через CNN и классифицирует с помощью SVM (глава 06). R-CNN был точным, но чрезвычайно медленным: он запускал CNN 2000 раз для каждого изображения.

- **Fast R-CNN** (Girshick, 2015) решил проблему избыточности, запустив CNN один раз на всем изображении для создания общей карты объектов, а затем извлекая функции для каждого предложения из этой общей карты с помощью **Объединения ROI** (Объединение областей интереса). 

- Объединение ROI берет область карты объектов переменного размера и создает выходные данные фиксированного размера путем разделения региона на сетку и максимального объединения внутри каждой ячейки. Это намного быстрее, поскольку дорогостоящие вычисления CNN происходят только один раз.

- **Faster R-CNN** (Ren et al., 2015) устранил алгоритм предложения внешнего региона, представив **Сеть предложений регионов (RPN)**, небольшую CNN, которая работает поверх общей карты объектов и напрямую прогнозирует предложения. RPN перемещает небольшое окно по карте объектов и в каждой позиции прогнозирует предложения $k$ (по одному для каждого **якоря**).

![Faster R-CNN pipeline: input image → backbone CNN → shared feature map → RPN generates proposals → RoI pooling → classification and box regression heads](../images/faster_rcnn.svg)- **Якорные рамки** — это предварительно определенные ограничивающие рамки в каждой пространственной позиции карты объектов, охватывающие разные масштабы и соотношения сторон (например, три масштаба $\times$ три соотношения = 9 привязок на позицию). RPN прогнозирует две вещи для каждой привязки: оценку объектности (объект против фона) и смещения координат, которые уточняют привязку до более точного предложения. Такая параметризация упрощает задачу регрессии: вместо прогнозирования абсолютных координат сеть прогнозирует небольшие корректировки разумного стартового поля.

- Смещения якорей параметризуются как:

$$t_x = \frac{x - x_a}{w_a}, \quad t_y = \frac{y - y_a}{h_a}, \quad t_w = \log\frac{w}{w_a}, \quad t_h = \log\frac{h}{h_a}$$

- где $(x, y, w, h)$ — предполагаемый центр и размер блока, а $(x_a, y_a, w_a, h_a)$ — якорь. Логарифмическое преобразование ширины и высоты гарантирует, что прогнозируемый блок всегда будет положительным, и делает регрессию инвариантной к масштабу.

- Более быстрое обучение R-CNN с потерей многозадачности: потеря классификации (перекрестная энтропия из главы 05) для метки класса плюс **плавная потеря L1** для блочной регрессии. Smooth L1 менее чувствителен к выбросам, чем L2:

```math
\text{smooth}_{L1}(x) = \begin{cases} 0.5x^2 & \text{if } |x| < 1 \\ |x| - 0.5 & \text{otherwise} \end{cases}
```

- **Сети функциональных пирамид (FPN)** (Lin et al., 2017) решают многомасштабную проблему, создавая нисходящий путь с боковыми связями, который объединяет семантику высокого уровня с пространственной детализацией низкого уровня. Магистральная сеть создает карты объектов в нескольких масштабах (каждый слой объединения уменьшает разрешение вдвое). FPN добавляет путь сверху вниз, где каждый уровень получает объекты с повышенной дискретизацией с уровня выше и объединяет их с соответствующим восходящим уровнем посредством боковых сверток 1x1. В результате получается пирамида карт объектов, каждая из которых имеет как сильную семантику, так и хорошее пространственное разрешение.

- Мелкие объекты обнаруживаются с уровней пирамиды более высокого разрешения; крупные объекты из уровней более низкого разрешения. FPN теперь является стандартным компонентом большинства современных архитектур обнаружения.

- **Одноэтапные детекторы** полностью пропускают этап предложения, предсказывая метки классов и ограничивающие рамки за один проход. Это быстрее, но исторически было менее точным, чем двухступенчатые детекторы, пока потеря фокуса не закрыла разрыв.

- **YOLO** (You Only Look Once, Redmon et al., 2016) делит изображение на сетку $S \times S$. Каждая ячейка сетки прогнозирует ограничивающие рамки $B$ и вероятности класса $C$. Если центр объекта попадает в ячейку сетки, эта ячейка отвечает за его обнаружение. YOLO работает чрезвычайно быстро, поскольку все обнаружение представляет собой один прямой проход без этапа предложения.

- **YOLov2** добавлены поля привязки, пакетная нормализация и многомасштабное обучение. **YOLOv3** использовал сеть пирамидных функций и делал прогнозы в трех масштабах. **YOLOv4-v8** продолжал совершенствоваться благодаря улучшенным магистральным сетям, сетям агрегации путей и дополнению мозаичных данных (склеиванию четырех изображений вместе во время обучения для увеличения контекстного разнообразия).

- **SSD** (Single Shot MultiBox Detector, Liu et al., 2016) выполняет прогнозирование в нескольких масштабах карты объектов внутри магистральной сети, используя поля привязки в каждом масштабе. Ранние карты объектов (высокого разрешения) обнаруживают небольшие объекты; более поздние карты (с низким разрешением) обнаруживают крупные объекты. SSD быстрее, чем Faster R-CNN, с конкурентоспособной точностью.

- **RetinaNet** (Лин и др., 2017) выявила основную проблему одноэтапных детекторов: дисбаланс классов. Подавляющее большинство ячеек привязки соответствуют фону, который генерирует легкие негативы, которые доминируют над потерями и подавляют градиенты редких положительных примеров.

– **Потеря фокуса** решает эту проблему за счет уменьшения веса простых примеров:

$$\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$$

- где $p_t$ — прогнозируемая вероятность для правильного класса. Когда модель уверена и правильна ($p_t$ имеет высокий уровень), $(1 - p_t)^\gamma$ мала, что снижает вклад потерь от простых негативов. Гиперпараметр $\gamma$ (обычно 2) управляет силой понижения веса. При использовании $\gamma = 0$ потеря фокуса снижается до стандартной перекрестной энтропии. Благодаря потере фокуса RetinaNet достигла точности, сравнимой с двухступенчатыми детекторами при одноступенчатой ​​скорости.

- **Обнаружение без привязки** полностью исключает поля привязки, уменьшая настройку гиперпараметров и упрощая конвейер.- **FCOS** (Fully Convolutional One-Stage, Tian et al., 2019) прогнозирует в каждой пространственной позиции карты объектов расстояния от этой позиции до четырех сторон ближайшего ограничивающего прямоугольника (слева, сверху, справа, снизу) плюс метку класса. Показатель **центрированности** снижает вес прогнозов вдали от центра объекта, что повышает качество. FCOS использует FPN для работы с несколькими масштабами.

- **CenterNet** (Zhou et al., 2019) определяет объекты как точки: прогнозирует тепловую карту, где пики соответствуют центрам объектов, а затем регрессирует ширину и высоту каждого пика. Обнаружение становится оценкой ключевой точки. Это элегантно и не требует привязки, но требует тщательной постобработки тепловой карты.

- **CornerNet** определяет объекты как пары углов (верхний левый и нижний правый). Он прогнозирует две тепловые карты (по одной для каждого типа углов) и использует **ассоциативное встраивание** для сопоставления соответствующих углов с ограничивающими рамками. Это позволяет избежать необходимости использования якорей и обрабатывать объекты произвольной формы.

– **Семантическая сегментация** присваивает метку класса каждому пикселю изображения. В отличие от обнаружения (которое выводит блоки), сегментация создает плотную карту на уровне пикселей. В уличной сцене каждый пиксель может быть помечен как дорога, тротуар, автомобиль, пешеход, здание, небо и т. д.

![Semantic segmentation: input street scene and its pixel-level label map where each colour represents a class](../images/semantic_segmentation.svg)

- **Полностью сверточные сети (FCN)** (Лонг и др., 2015) адаптировали классификационные CNN для сегментации, заменив полностью связанные слои сверточными слоями, что позволяет сети выводить пространственную карту, а не один класс. Повышение дискретизации (посредством транспонированной свертки или билинейной интерполяции) восстанавливает выходное разрешение до входного разрешения. Пропуск соединений из более ранних слоев возвращает пространственные детали, потерянные при понижении разрешения.

- **Транспонированная свертка** (иногда называемая «деконволюцией») — это аналог свертки с повышающей дискретизацией. Если ступенчатая свертка уменьшает пространственные размеры, то транспонированная свертка увеличивает их. Он вставляет нули между входными элементами, а затем применяет стандартную свертку, эффективно обучаясь повышению дискретизации.

- **U-Net** (Роннебергер и др., 2015) представила симметричную архитектуру кодера-декодера с пропуском соединений на каждом уровне. Кодер (сужающийся путь) снижает пространственное разрешение при увеличении количества каналов, точно так же, как классифицирующая CNN. Декодер (расширяющийся путь) повышает дискретизацию до полного разрешения. Пропускные соединения объединяют карты функций кодера с картами функций декодера на каждом уровне, обеспечивая декодеру точную пространственную детализацию. Такое сочетание семантики высокого уровня и детализации низкого уровня обеспечивает четкие и точные границы сегментации.

![U-Net architecture: encoder path on the left with downsampling, decoder path on the right with upsampling, and skip connections bridging corresponding levels](../images/unet_architecture.svg)

- U-Net изначально был разработан для сегментации биомедицинских изображений (когда данных для обучения недостаточно), и его архитектура стала основой для многих последующих моделей, включая U-Net в моделях скрытой диффузии (файл 04).

- **DeepLab** (Чен и др., 2014–2018) представила две ключевые инновации в сегментации:

    - **Атрическая (расширенная) извилина**: стандартная извилина с промежутками между фильтрующими элементами, контролируемая степенью расширения $r$. Фильтр 3x3 с расширением $r$ имеет рецептивное поле $(2r + 1) \times (2r + 1)$, используя при этом всего 9 параметров. Это фиксирует контекст в нескольких масштабах без понижения разрешения, сохраняя пространственное разрешение.

    - **Атросное пространственное пирамидальное объединение (ASPP)**: параллельно применяет несколько атросных сверток с разными скоростями расширения (например, скорости 1, 6, 12, 18), объединяет результаты и объединяет их со сверткой 1x1. ASPP фиксирует контекст в нескольких масштабах одновременно, аналогично начальному модулю (файл 02), но с использованием расширения вместо разных размеров ядра.

- DeepLab также использовала **Условное случайное поле (CRF)** (глава 05) в качестве этапа постобработки для уточнения границ сегментации, поощряя пространственно близкие пиксели схожих цветов использовать одну и ту же метку.

- **Сегментация экземпляров** сочетает в себе обнаружение и сегментацию: она идентифицирует каждый отдельный экземпляр объекта и создает для каждого маску на уровне пикселей. Две машины в сцене получают две отдельные маски, а не просто «машина» для обеих.- **Mask R-CNN** (He et al., 2017) расширяет Faster R-CNN, добавляя небольшую головку сегментации, которая прогнозирует двоичную маску для каждого обнаруженного объекта. Архитектура представляет собой Faster R-CNN + ветвь маски: ветвь маски принимает функции, объединенные в пул RoI, и выводит двоичную маску $m \times m$ для каждого класса. Он использует **RoIAlign** вместо объединения RoI: билинейную интерполяцию в точно выбранных точках, а не в квантованных ячейках сетки, что позволяет избежать пространственного смещения, вызываемого квантованием. Это небольшое изменение значительно улучшает качество маски.

- Маска R-CNN обучается с многозадачной потерей: потеря классификации + потеря блочной регрессии + потеря маски (попиксельная двоичная кросс-энтропия). Ветка маски прогнозирует маску для каждого класса независимо; используется только маска, соответствующая прогнозируемому классу, что отделяет прогнозирование маски от классификации и улучшает и то, и другое.

- **Паноптическая сегментация** объединяет семантическую сегментацию и сегментацию экземпляров в одну задачу. Каждый пиксель получает как метку класса (семантику), так и идентификатор экземпляра (например, для классов «вещей», таких как автомобили и люди). Классы «вещей» (небо, дорога, трава) получают только семантические метки, поскольку они представляют собой аморфные области без счетных экземпляров.

- Метрика паноптического качества (PQ) оценивает это путем разложения на качество сегментации (среднее IoU совпадающих сегментов) и качество распознавания (оценка F1 совпадающих сегментов):

$$\text{PQ} = \underbrace{\frac{\sum_{(p,g) \in \text{TP}} \text{IoU}(p,g)}{|\text{TP}|}}_{\text{SQ}} \times \underbrace{\frac{|\text{TP}|}{|\text{TP}| + \frac{1}{2}|\text{FP}| + \frac{1}{2}|\text{FN}|}}_{\text{RQ}}$$

- **Сегментация в реальном времени** имеет решающее значение для таких приложений, как автономное вождение и дополненная реальность, где бюджеты задержек ограничены (часто менее 30 миллисекунд на кадр).

- **BiSeNet** (Сеть двусторонней сегментации, Ю и др., 2018) использует два параллельных пути: **пространственный путь** с широкими и мелкими слоями, который сохраняет пространственные детали, и **контекстный путь** с глубокими и узкими слоями, который фиксирует семантику. Выходы объединены, что обеспечивает скорость и точность.

- **DDRNet** (Deep Dual-Resolution Network, Hong et al., 2021) поддерживает две ветви с разным разрешением по всей сети с повторяющимся обменом информацией между ними. Ветка с высоким разрешением сохраняет пространственные детали, а ветвь с низким разрешением фиксирует глобальный контекст. Множественные двусторонние модули слияния объединяют информацию в обоих направлениях.

- Общая тенденция в сегментации в реальном времени заключается в том, чтобы избегать сложной схемы кодирования-декодера и вместо этого поддерживать достаточное пространственное разрешение во всей сети, жертвуя некоторой точностью ради значительно меньшей задержки.

1. Реализуйте вычисление IoU и немаксимальное подавление с нуля. Примените NMS к набору перекрывающихся ограничивающих рамок и визуализируйте результат.
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt
import matplotlib.patches as patches

def compute_iou(box1, box2):
    """Compute IoU between two boxes [x1, y1, x2, y2]."""
    x1 = jnp.maximum(box1[0], box2[0])
    y1 = jnp.maximum(box1[1], box2[1])
    x2 = jnp.minimum(box1[2], box2[2])
    y2 = jnp.minimum(box1[3], box2[3])

    intersection = jnp.maximum(0, x2 - x1) * jnp.maximum(0, y2 - y1)
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - intersection

    return intersection / (union + 1e-6)

def nms(boxes, scores, iou_threshold=0.5):
    """Non-Maximum Suppression."""
    order = jnp.argsort(-scores)  # sort by descending confidence
    keep = []

    remaining = list(range(len(scores)))
    order_list = order.tolist()

    while order_list:
        idx = order_list[0]
        keep.append(idx)
        order_list = order_list[1:]

        new_order = []
        for j in order_list:
            iou = compute_iou(boxes[idx], boxes[j])
            if iou < iou_threshold:
                new_order.append(j)
        order_list = new_order

    return keep

# Example: overlapping detections of the same object
boxes = jnp.array([
    [50, 60, 150, 160],   # high confidence
    [55, 65, 155, 165],   # overlapping duplicate
    [52, 58, 148, 158],   # overlapping duplicate
    [200, 100, 300, 200], # different object
    [205, 105, 305, 205], # overlapping duplicate
])
scores = jnp.array([0.95, 0.80, 0.70, 0.90, 0.60])

keep = nms(boxes, scores, iou_threshold=0.5)

fig, axes = plt.subplots(1, 2, figsize=(14, 5))
colors = ['#3498db', '#e74c3c', '#27ae60', '#9b59b6', '#f39c12']

for ax, title, indices in zip(axes, ['Before NMS', 'After NMS'],
                               [range(len(boxes)), keep]):
    ax.set_xlim(0, 400); ax.set_ylim(0, 300)
    ax.set_aspect('equal'); ax.invert_yaxis()
    ax.set_title(title)
    for i in indices:
        b = boxes[i]
        rect = patches.Rectangle((b[0], b[1]), b[2]-b[0], b[3]-b[1],
                                  linewidth=2, edgecolor=colors[i],

        ax.add_patch(rect)
        ax.text(b[0], b[1]-5, f'{scores[i]:.2f}', color=colors[i], fontsize=10)

plt.tight_layout(); plt.show()
print(f"Kept {len(keep)} of {len(boxes)} boxes after NMS")
```

```python
def generate_anchors(feature_h, feature_w, stride, scales, ratios):
    """Generate anchor boxes for each position on the feature map."""
    anchors = []
    for y in range(feature_h):
        for x in range(feature_w):
            cx = (x + 0.5) * stride
            cy = (y + 0.5) * stride
            for s in scales:
                for r in ratios:
                    w = s * jnp.sqrt(r)
                    h = s / jnp.sqrt(r)
                    anchors.append([cx - w/2, cy - h/2, cx + w/2, cy + h/2])
```

3. Реализовать упрощенный кодер-декодер U-Net с пропуском соединений для 1D-сегментации (двоичная маркировка 1D-сигнала).
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def conv1d_same(x, kernel):
    """1D convolution with same padding."""
    k = len(kernel)
    pad = k // 2
    x_pad = jnp.pad(x, pad, mode='edge')
    n = len(x)
    out = jnp.zeros(n)
    for i in range(n):
        out = out.at[i].set(jnp.sum(x_pad[i:i+k] * kernel))
    return out

def downsample(x):
    return x[::2]

def upsample(x, target_len):
    return jnp.interp(jnp.linspace(0, 1, target_len), jnp.linspace(0, 1, len(x)), x)

def unet_1d(x, params):
    """Simplified 1D U-Net with 2 encoder/decoder levels."""
    # Encoder
    e1 = jnp.maximum(0, conv1d_same(x, params['enc1']))
    e1_down = downsample(e1)

    e2 = jnp.maximum(0, conv1d_same(e1_down, params['enc2']))
    e2_down = downsample(e2)

    # Bottleneck
    bottleneck = jnp.maximum(0, conv1d_same(e2_down, params['bottleneck']))

    # Decoder with skip connections
    d2_up = upsample(bottleneck, len(e2))
    d2 = jnp.maximum(0, conv1d_same(d2_up + e2, params['dec2']))  # skip connection

    d1_up = upsample(d2, len(e1))
    d1 = conv1d_same(d1_up + e1, params['dec1'])  # skip connection

    return jax.nn.sigmoid(d1)

# Create signal with labelled regions
n = 128
t = jnp.linspace(0, 4 * jnp.pi, n)
signal = jnp.sin(t) + 0.5 * jnp.sin(3 * t)
labels = (signal > 0.5).astype(jnp.float32)  # binary segmentation target

key = jax.random.PRNGKey(42)
keys = jax.random.split(key, 5)
params = {
    'enc1': jax.random.normal(keys[0], (5,)) * 0.3,
    'enc2': jax.random.normal(keys[1], (5,)) * 0.3,
    'bottleneck': jax.random.normal(keys[2], (3,)) * 0.3,
    'dec2': jax.random.normal(keys[3], (5,)) * 0.3,
    'dec1': jax.random.normal(keys[4], (5,)) * 0.3,
}

def loss_fn(params, signal, labels):
    pred = unet_1d(signal, params)
    return -jnp.mean(labels * jnp.log(pred + 1e-7) + (1 - labels) * jnp.log(1 - pred + 1e-7))

grad_fn = jax.jit(jax.grad(loss_fn))
lr = 0.05

for step in range(500):
    grads = grad_fn(params, signal, labels)
    params = {k: params[k] - lr * grads[k] for k in params}

pred = unet_1d(signal, params)

fig, axes = plt.subplots(3, 1, figsize=(12, 7), sharex=True)
axes[0].plot(t, signal, color='#3498db', linewidth=1.5)
axes[0].set_title('Input Signal'); axes[0].set_ylabel('Value')

axes[1].fill_between(t, 0, labels, alpha=0.3, color='#27ae60')
axes[1].set_title('Ground Truth Labels'); axes[1].set_ylabel('Label')

axes[2].plot(t, pred, color='#e74c3c', linewidth=1.5)
axes[2].fill_between(t, 0, (pred > 0.5).astype(float), alpha=0.2, color='#e74c3c')
axes[2].set_title('U-Net Prediction'); axes[2].set_ylabel('Probability')
axes[2].set_xlabel('t')

plt.tight_layout(); plt.show()
print(f"Final loss: {loss_fn(params, signal, labels):.4f}")
print(f"Pixel accuracy: {jnp.mean((pred > 0.5) == labels):.2%}")
```
