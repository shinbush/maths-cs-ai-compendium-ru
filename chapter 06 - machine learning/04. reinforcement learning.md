# Обучение с подкреплением

*Обучение с подкреплением обучает агентов принимать последовательные решения, максимизируя совокупное вознаграждение методом проб и ошибок. В этом файле описаны MDP, функции стоимости, уравнения Беллмана, Q-обучение, градиенты политики, методы «актёр-критик», PPO и RLHF, основа игровых агентов и согласование языковых моделей.*

- Для контролируемого обучения необходимы маркированные данные. Обучение без учителя находит закономерности в неразмеченных данных. **Обучение с подкреплением (RL)** отличается от обоих: агент учится, взаимодействуя с окружающей средой, выполняя действия и получая вознаграждение. Нет правильных ярлыков; агент должен обнаружить хорошее поведение методом проб и ошибок.

- Подумайте о том, чтобы научить собаку новому трюку. Вы не показываете ему набор данных о правильном поведении. Вместо этого он пробует что-то, вы даете угощение за хорошие действия, и со временем он понимает, чего вы хотите. RL формализует этот процесс.

- Установка RL состоит из пяти основных компонентов. **Агент** — это обучающийся и принимающий решения. **Среда** — это все, что находится за пределами агента, с чем он взаимодействует. На каждом временном шаге агент наблюдает **состояние** $s_t$, выбирает **действие** $a_t$, получает **награду** $r_t$ и переходит в новое состояние $s_{t+1}$. Цель агента — максимизировать общее вознаграждение, которое он собирает с течением времени.

![Agent-environment loop: agent observes state, takes action, receives reward, environment transitions to new state](../images/mdp_agent_loop.svg)

- **Политика** $\pi$ — это стратегия агента: отображение состояний в действия. Детерминированная политика дает одно действие на каждое состояние: $a = \pi(s)$. Стохастическая политика дает распределение вероятностей действий: $\pi(a \mid s)$. Цель RL — найти оптимальную политику, которая максимизирует ожидаемое совокупное вознаграждение.

- Математической основой для RL является **Марковский процесс принятия решений (MDP)**, определяемый кортежем $(S, A, P, R, \gamma)$: набор состояний $S$, набор действий $A$, вероятности перехода $P(s' \mid s, a)$, функция вознаграждения. $R(s, a)$ и коэффициент скидки $\gamma$.

- **Свойство Маркова** (из главы 05) говорит, что будущее зависит только от текущего состояния, а не от истории того, как вы туда попали: $P(s_{t+1} \mid s_t, a_t, s_{t-1}, \ldots) = P(s_{t+1} \mid s_t, a_t)$. Это означает, что состояние содержит всю информацию, необходимую для принятия решения.

- **Коэффициент скидки** $\gamma \in [0, 1)$ определяет, насколько агент заботится о будущих вознаграждениях по сравнению с немедленными. Скидка на прибыль со времени $t$ составляет:

$$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$$

- С $\gamma = 0$ агент совершенно близорук, заботясь только о следующей награде. Если значение $\gamma$ близко к 1, агент является дальновидным. Коэффициент дисконтирования также обеспечивает сходимость суммы (если вознаграждение ограничено), что важно для математической четкости.

- **Функции ценности** оценивают, насколько хорошо находиться в каком-то состоянии (или совершать действия в этом состоянии). **функция значения состояния** $V^\pi(s)$ — это ожидаемый доход, начиная с состояния $s$ и следующей политики $\pi$:

$$V^\pi(s) = \mathbb{E}_\pi \left[ G_t \mid s_t = s \right]$$

- **функция значения действия** $Q^\pi(s, a)$ — это ожидаемый возврат, начиная с состояния $s$, выполняя действие $a$, а затем следуя $\pi$:

$$Q^\pi(s, a) = \mathbb{E}_\pi \left[ G_t \mid s_t = s, a_t = a \right]$$

- Отношения: $V^\pi(s) = \sum_a \pi(a \mid s) \, Q^\pi(s, a)$. Значение состояния — это среднее значение действий, взвешенное политикой.

- **Уравнение Беллмана** выражает рекурсивную зависимость: ценность состояния равна немедленной награде плюс дисконтированная стоимость следующего состояния. Для функции значения состояния:

$$V^\pi(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \, V^\pi(s') \right]$$

- Для функции оптимального значения $V^{*}(s)$ агент всегда выбирает лучшее действие:

$$V^{*}(s) = \max_a \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \, V^{*}(s') \right]$$

- Аналогично **уравнение оптимальности Беллмана** для $Q^{*}$:

$$Q^{*}(s, a) = \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \max_{a'} Q^{*}(s', a') \right]$$

- Если у вас есть $Q^{*}$, оптимальная политика тривиальна: всегда выбирайте действие с наибольшим значением Q: $\pi^{*}(s) = \arg\max_a Q^{*}(s, a)$.- Методы **динамического программирования** решают MDP, когда известны вероятности перехода и вознаграждения (полная модель). **Оценка политики** вычисляет $V^\pi$ для заданной политики путем итеративного применения уравнения Беллмана до достижения сходимости. **Улучшение политики** берет функцию ценности и строит лучшую политику, действуя жадно: $\pi'(s) = \arg\max_a \sum_{s'} P(s' \mid s, a)[R(s,a) + \gamma V^\pi(s')]$.

– **Итерация политики** чередует оценку и улучшение, пока политика не перестанет меняться. Гарантировано сходится к оптимальной политике.

- **Итерация значения** объединяет оба шага в один: он неоднократно применяет уравнение оптимальности Беллмана до тех пор, пока $V^{*}$ не сойдется, а затем извлекает политику.

$$V(s) \leftarrow \max_a \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \, V(s') \right]$$

- Динамическое программирование требует знания $P(s' \mid s, a)$, что зачастую непрактично. В большинстве реальных задач агент не знает динамики окружающей среды; он может только взаимодействовать с ним. Именно здесь на помощь приходят **методальные** методы.

- **Обучение временной разнице (TD)** учится на основе опыта, не зная модели. Ключевая идея — **начальная загрузка**: вместо того, чтобы ждать окончания эпизода для вычисления фактического дохода $G_t$, вы оцениваете его с помощью функции текущего значения:

$$V(s_t) \leftarrow V(s_t) + \alpha \left[ r_t + \gamma \, V(s_{t+1}) - V(s_t) \right]$$

- Термин в скобках означает **ошибку TD**: разницу между **целевым значением TD** ($r_t + \gamma V(s_{t+1})$) и текущей оценкой $V(s_t)$. Если ошибка TD положительна, состояние было лучше, чем ожидалось, поэтому мы увеличиваем ее значение. Если отрицательно, уменьшаем.

![State transition showing TD target: current value, reward, and bootstrapped next value with the update formula](../images/td_update.svg)

- Обучение TD обновляется после каждого шага (а не после полных эпизодов), что делает его намного более эффективным, чем методы Монте-Карло. Он также работает в продолжающихся (неэпизодических) средах.

- **SARSA** (Состояние-Действие-Награда-Состояние-Действие) — это TD-обучение, применяемое к Q-значениям. Агент выполняет действие $a$ в состоянии $s$, наблюдает за вознаграждением $r$ и следующим состоянием $s'$, затем выбирает следующее действие $a'$ в соответствии со своей политикой:

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \, Q(s', a') - Q(s, a) \right]$$

- SARSA **соблюдает политику**: она обновляет информацию, используя действия, которые фактически выполняет агент, включая исследование. Это делает SARSA более консервативным; он изучает политику, которая учитывает его собственный шум исследования.

- **Q-learning** — самый известный алгоритм RL. Это похоже на SARSA, но вместо того, чтобы использовать действие, которое фактически предпринимает агент, он использует наилучшее из возможных действий:

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

- Q-обучение **не соответствует политике**: оно изучает оптимальные значения Q независимо от соблюдаемой политики. Агент может исследовать случайным образом, при этом изучая оптимальные значения действий. Это делает Q-обучение более агрессивным и часто быстрее сходящимся, но может переоценивать значения.

- **Исследование против эксплуатации** — это фундаментальная дилемма: должен ли агент использовать то, что он уже знает (выбрать действие с наибольшей оценочной ценностью) или исследовать неизвестные действия (которые могут оказаться лучше)?

- Самая простая стратегия — **эпсилон-жадная**: с вероятностью $\epsilon$ совершить случайное действие (исследовать); с вероятностью $1 - \epsilon$ совершить жадное действие (эксплойт). Обычный график начинается с высокого значения $\epsilon$ (много исследований) и со временем снижается.

- Табличные методы (хранящие значение для каждой пары состояние-действие в таблице) работают для небольших дискретных пространств состояний. Для больших или непрерывных пространств состояний вам необходима аппроксимация функции. **Deep Q-Networks (DQN)** использует нейронную сеть для аппроксимации $Q(s, a; \theta)$, где $\theta$ — веса сети.

- DQN представила два критически важных метода стабилизации. **Воспроизведение**: вместо обучения на последовательных переходах (которые сильно коррелируют), сохраняйте переходы в буфере воспроизведения и выбирайте случайные мини-пакеты для обучения. Это нарушает корреляции и позволяет эффективно повторно использовать данные.- **Целевая сеть**: используйте отдельную, медленно обновляемую копию сети для вычисления целей TD. Без этого цель перемещается каждый раз, когда вы обновляете сеть, создавая нестабильность «погони за собственным хвостом». Целевая сеть обновляется периодически (жесткое обновление каждые шаги $N$) или постоянно (мягкое обновление: $\theta^{-} \leftarrow \tau\theta + (1-\tau)\theta^{-}$).

- Потеря DQN - это всего лишь MSE между прогнозируемыми значениями Q и целевыми значениями TD:

$$\mathcal{L}(\theta) = \mathbb{E} \left[ \left( r + \gamma \max_{a'} Q(s', a'; \theta^{-}) - Q(s, a; \theta) \right)^2 \right]$$

- Все методы на данный момент изучают функции стоимости и выводят из них политику. Методы **градиента политики** используют другой подход: они напрямую параметризуют политику $\pi(a \mid s; \theta)$ и оптимизируют ее путем градиентного подъема при ожидаемом доходе.

- **Теорема о градиенте политики** дает градиент ожидаемой доходности в зависимости от параметров политики:

$$\nabla_\theta J(\theta) = \mathbb{E}_\pi \left[ \nabla_\theta \log \pi(a \mid s; \theta) \cdot G_t \right]$$

- Здесь говорится: увеличьте вероятность действий, которые привели к высокой прибыли, уменьшите вероятность действий, которые привели к низкой прибыли. Логарифмический градиент вероятности указывает направление изменения политики, а $G_t$ масштабирует степень ее изменения.

- **REINFORCE** — это самый простой алгоритм градиента политики. Запустите эпизод, вычисления вернут $G_t$ для каждого шага и обновите:

$$\theta \leftarrow \theta + \alpha \, \nabla_\theta \log \pi(a_t \mid s_t; \theta) \cdot G_t$$

- REINFORCE имеет высокую дисперсию, поскольку $G_t$ представляет собой зашумленную оценку ожидаемой доходности для одной выборки. Распространенным решением является вычитание **базового уровня** (обычно средней доходности или функции полученного значения), чтобы уменьшить дисперсию без внесения систематической ошибки:

$$\theta \leftarrow \theta + \alpha \, \nabla_\theta \log \pi(a_t \mid s_t; \theta) \cdot (G_t - b)$$

- Методы **Актер-Критик** используют две сети. **Субъект** — это политика $\pi(a \mid s; \theta)$. **Критик** — это функция значения $V(s; \phi)$, которая служит базовой линией. Преимущество $A_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ заменяет $G_t - b$:

$$\theta \leftarrow \theta + \alpha \, \nabla_\theta \log \pi(a_t \mid s_t; \theta) \cdot A_t$$

- Критик обновляется путем минимизации ошибки TD, как и методы, основанные на значениях. Актор обновляется с использованием градиента политики, при этом оценка преимущества критика уменьшает дисперсию. Это лучшее из обоих миров.

![Two-headed architecture: actor outputs action probabilities, critic outputs value estimate, advantage signal guides actor updates](../images/actor_critic.svg)

- **PPO** (оптимизация проксимальной политики) — наиболее широко используемый на практике алгоритм градиента политики. Это решает ключевую проблему: если обновление политики слишком велико, производительность может катастрофически упасть.

- PPO использует **обрезанный суррогатный объектив**. Пусть $r_t(\theta) = \frac{\pi(a_t | s_t; \theta)}{\pi(a_t | s_t; \theta_{\text{old}})}$ — отношение вероятностей между новой и старой политикой. Убыток составляет:

$$\mathcal{L}^{\text{CLIP}}(\theta) = \mathbb{E} \left[ \min\!\left( r_t(\theta) A_t, \; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t \right) \right]$$

- Отсечение (обычно $\epsilon = 0.2$) предотвращает слишком большое отклонение отношения от 1, что обеспечивает небольшой размер и стабильность обновлений. Если преимущество положительное (действие было хорошим), соотношение ограничивается значением $1 + \epsilon$. В случае отрицательного результата (действие было плохим), коэффициент ограничивается значением $1 - \epsilon$. Это проще и стабильнее, чем более ранние методы доверительной области (TRPO).

- PPO — это то, что использовалось для обучения моделей в стиле ChatGPT через **RLHF** (обучение с подкреплением на основе отзывов пользователей). В RLHF модель вознаграждения обучается на данных о предпочтениях человека (какой из двух выходных данных люди предпочитают?), а затем PPO оптимизирует политику языковой модели, чтобы максимизировать это изученное вознаграждение.

- **DPO** (прямая оптимизация предпочтений) упрощает RLHF, полностью устраняя модель вознаграждения. Вместо обучения модели вознаграждения и последующего запуска RL, DPO получает потери в закрытой форме, которые напрямую оптимизируют политику на основе данных о предпочтениях:

$$\mathcal{L}_{\text{DPO}}(\theta) = -\mathbb{E} \left[ \log \sigma\!\left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)} \right) \right]$$

- Здесь $y_w$ — предпочтительный (выигрышный) ответ, а $y_l$ — непредпочтительный (проигрышный) ответ. DPO увеличивает относительную вероятность предпочтительных результатов и его гораздо проще реализовать, чем RLHF на основе PPO.

- Два важных различия в алгоритмах RL. **В соответствии с политикой или вне политики**: методы, соответствующие политике (SARSA, PPO), обучаются на основе данных, генерируемых текущей политикой; методы вне политики (Q-learning, DQN) могут учиться на данных, генерируемых любой политикой. Методы, не соответствующие политике, более эффективны с точки зрения выборки (они повторно используют старые данные), но могут быть менее стабильными.- **На основе моделей и без моделей**: методы без моделей (все, что обсуждалось до сих пор) изучают ценности или политики непосредственно на основе опыта. Методы, основанные на моделях, изучают модель окружающей среды ($P(s' \mid s, a)$ и $R(s, a)$) и используют ее для планирования (представление будущих траекторий без фактических действий). Методы, основанные на моделях, более эффективны при использовании выборки, но усложняют изучение точной модели.

- Подводя итог ландшафту RL:

| Метод | Тип | Ключевая идея | Сила |
|---|---|---|---|
| Итерация значений | ДП, на основе модели | Оптимальность Беллмана | Точное решение (малые MDP) |
| САРСА | ТД, по политике | Узнайте Q о политике | Консервативный, безопасный |
| Q-обучение | ТД, вне политики | Выучи Q*, жадная мишень | Просто, эффективно |
| ДКН | Глубокий, вне политики | Neural Q + воспроизведение + целевая сеть | Масштабируется до состояний высокой тусклости |
| УСИЛИТЬ | Градиент политики | Градиент log-prob * return | Простая оптимизация политики |
| Актер-критик | PG + значение | Актер + критик за низкую дисперсию | Практичный и гибкий |
| ППО | PG, обрезанный | Стабильность, подобная доверительному региону | Отраслевой стандарт |
| ДПО | Прямое предпочтение | Пропустить модель вознаграждения | Проще RLHF |

```python
            V_new = V_new.at[i, j].set(max(values))
    if jnp.max(jnp.abs(V_new - V)) < 1e-6:
        print(f"Converged in {iteration+1} iterations")
        break
    V = V_new

# Extract policy
policy = [['' for _ in range(grid_size)] for _ in range(grid_size)]
for i in range(grid_size):
    for j in range(grid_size):
        if (i, j) == goal:
            policy[i][j] = 'G'
            continue
        best_a = max(range(4), key=lambda a: -1 + gamma * float(V[step((i,j), actions[a])[0], step((i,j), actions[a])[1]]))
        policy[i][j] = action_arrows[best_a]

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
im = axes[0].imshow(V, cmap='YlOrRd_r')
axes[0].set_title("Optimal Value Function")
for i in range(grid_size):
    for j in range(grid_size):
        axes[0].text(j, i, f"{V[i,j]:.1f}", ha='center', va='center', fontsize=10)
plt.colorbar(im, ax=axes[0])

axes[1].imshow(jnp.ones((grid_size, grid_size)), cmap='Greys', vmin=0, vmax=2)
axes[1].set_title("Optimal Policy")
for i in range(grid_size):
    for j in range(grid_size):
        axes[1].text(j, i, policy[i][j], ha='center', va='center', fontsize=18)
plt.tight_layout(); plt.show()
```

2. Реализуйте табличное Q-обучение в простом сетчатом мире. Обучите агента, постройте кривую обучения и покажите полученные значения Q.
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

grid_size = 5
goal = (4, 4)
actions = [(-1,0), (1,0), (0,-1), (0,1)]

# Q-table
Q = {}
for i in range(grid_size):
    for j in range(grid_size):
        Q[(i,j)] = [0.0] * 4

alpha = 0.1
gamma = 0.95
epsilon = 1.0
epsilon_decay = 0.995
min_epsilon = 0.01

def step(s, a_idx):
    a = actions[a_idx]
    ns = (max(0, min(grid_size-1, s[0]+a[0])),
          max(0, min(grid_size-1, s[1]+a[1])))
    r = 0.0 if ns == goal else -1.0
    done = ns == goal
    return ns, r, done

key = jax.random.PRNGKey(42)
rewards_per_episode = []

for ep in range(500):
    s = (0, 0)
    total_reward = 0
    for _ in range(100):
        key, subkey = jax.random.split(key)
        if float(jax.random.uniform(subkey)) < epsilon:
            key, subkey = jax.random.split(key)
            a = int(jax.random.randint(subkey, (), 0, 4))
        else:
            a = max(range(4), key=lambda i: Q[s][i])

        ns, r, done = step(s, a)
        total_reward += r
        # Q-learning update
        Q[s][a] += alpha * (r + gamma * max(Q[ns]) - Q[s][a])
        s = ns
        if done:
            break
    rewards_per_episode.append(total_reward)
    epsilon = max(min_epsilon, epsilon * epsilon_decay)

plt.figure(figsize=(8, 4))
# Smooth the curve
window = 20
smoothed = [sum(rewards_per_episode[max(0,i-window):i+1])/min(i+1, window)
            for i in range(len(rewards_per_episode))]
plt.plot(smoothed, color='#3498db', linewidth=1.5)
plt.xlabel("Episode"); plt.ylabel("Total Reward (smoothed)")
plt.title("Q-Learning on Gridworld")
plt.grid(alpha=0.3); plt.show()

# Show learned policy
arrow = ['\u2191', '\u2193', '\u2190', '\u2192']
print("Learned policy:")
for i in range(grid_size):
    row = ""
    for j in range(grid_size):
        if (i,j) == goal:
            row += " G "
        else:
            row += f" {arrow[max(range(4), key=lambda a: Q[(i,j)][a])]} "
    print(row)
```

3. Примените REINFORCE для решения задачи о многоруком бандите. Покажите, как политика меняется в зависимости от обучения, отдавая предпочтение лучшим специалистам.

```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

# 5-armed bandit with different expected rewards
true_rewards = jnp.array([0.2, 0.5, 0.8, 0.3, 0.1])
n_arms = len(true_rewards)

# Policy: softmax over logits
logits = jnp.zeros(n_arms)
lr = 0.1
key = jax.random.PRNGKey(42)

policy_history = []
reward_history = []

for step in range(2000):
    probs = jax.nn.softmax(logits)
    policy_history.append(probs)

    # Sample action
    key, subkey = jax.random.split(key)
    action = jax.random.choice(subkey, n_arms, p=probs)

    # Get reward (Bernoulli)
    key, subkey = jax.random.split(key)
    reward = float(jax.random.uniform(subkey) < true_rewards[action])
    reward_history.append(reward)

    # REINFORCE update
    # grad log pi(a) = e_a - probs (for softmax parameterisation)
    grad_log_pi = -probs.at[action].add(1.0)  # one-hot(a) - probs
    logits = logits + lr * reward * grad_log_pi

policy_history = jnp.stack(policy_history)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
colors = ['#3498db', '#e74c3c', '#27ae60', '#9b59b6', '#f39c12']
for i in range(n_arms):
    axes[0].plot(policy_history[:, i], color=colors[i],
                 label=f'Arm {i} (true={true_rewards[i]:.1f})', linewidth=1.5)
axes[0].set_xlabel("Step"); axes[0].set_ylabel("P(arm)")
axes[0].set_title("Policy Evolution (REINFORCE)")
axes[0].legend(fontsize=8); axes[0].grid(alpha=0.3)

# Smoothed reward
window = 50

            for i in range(len(reward_history))]
```
