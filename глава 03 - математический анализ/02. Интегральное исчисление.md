# Интегральное исчисление

*Интегральное исчисление накапливает количества за интервалы, превращая местные ставки обратно в итоговые суммы. В этом файле описаны определенные и неопределенные интегралы, Фундаментальная теорема исчисления, методы интегрирования и приложения к плотностям вероятности и ожидаемым значениям в ML.*

- Дифференциация показывает нам скорость изменения в отдельной точке. Интеграция идет другим путем: она накапливает множество крошечных частей для вычисления общей суммы. 

- Если производная отвечает «как быстро?», интеграл отвечает «сколько?»

- Самый простой способ представить интеграцию – это **площадь под кривой**. Если вы построите график функции $f(x)$ и закрасите область между кривой и осью X от $x = a$ до $x = b$, интеграл даст площадь этой области со знаком.

![Integration computes the area under a curve by summing thin rectangles](../images/area_under_curve.svg)

- Почему «подписанный»? Области выше оси X дают положительную площадь, а регионы ниже — отрицательную. Это имеет физический смысл: если $f(x)$ представляет скорость, интеграл дает чистое смещение (вперед минус назад), а не общее расстояние.

- Чтобы вычислить эту площадь, представьте, что вы разрезаете область на тонкие вертикальные прямоугольники $n$, каждый шириной $\Delta x$. Высота каждого прямоугольника — это значение функции в некоторой точке этого среза. Подведите итоги:

$$\text{Area} \approx \sum_{i=1}^{n} f(x_i^\ast) \, \Delta x$$

- По мере того, как мы делаем прямоугольники все тоньше и тоньше ($n \to \infty$, $\Delta x \to 0$), сумма становится точной. Этот предельный процесс определяет **определенный интеграл**:

$$\int_a^b f(x)\, dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^\ast) \, \Delta x$$

- Символ $\int$ представляет собой удлиненную букву S, обозначающую «сумму». $dx$ напоминает нам, что мы суммируем бесконечно тонкие срезы вдоль оси X.

- **Неопределенный интеграл** (или **перпроизводная**) – это функция $F(x)$, производная которой равна $f(x)$. Мы пишем:

$$\int f(x)\, dx = F(x) + C$$

- $+ C$ — это **константа интегрирования**. Поскольку производная любой константы равна нулю, существует бесконечно много первообразных, отличающихся только константой. Например, $\int 2x\, dx = x^2 + C$, поскольку производная от $x^2 + 7$ или $x^2 - 3$ по-прежнему равна $2x$.

- **Фундаментальная теорема исчисления** — это мост, соединяющий дифференцирование и интегрирование. Он состоит из двух частей:

- **Часть 1**: Если $F(x)$ является первообразной от $f(x)$, то определенный интеграл равен разности $F$ в конечных точках:

$$\int_a^b f(x)\, dx = F(b) - F(a)$$

- Это удивительно практично. Вместо вычисления предела суммы (что сложно) мы находим первообразную и вычисляем ее в двух точках (что обычно несложно).

- **Часть 2**: Если мы определим $F(x) = \int_a^x f(t)\, dt$, то $F'(x) = f(x)$. Дифференцирование и интегрирование — обратные операции, они аннулируют друг друга.

- Например, для вычисления $\int_1^3 x^2\, dx$: первообразной от $x^2$ является $\frac{x^3}{3}$. Итак, $\int_1^3 x^2\, dx = \frac{27}{3} - \frac{1}{3} = \frac{26}{3} \approx 8.67$.

- Точно так же, как у дифференциации есть правила, у интеграции есть соответствующие правила, которые меняют их:

| Функция | Интеграл | Состояние |
|---|---|---|
| $x^n$ | $\frac{x^{n+1}}{n+1} + C$ | $n \neq -1$ |
| $\frac{1}{x}$ | $\ln\|x\| + C$ | |
| $e^x$ | $e^x + C$ | |
| $a^x$ | $\frac{a^x}{\ln a} + C$ | |
| $\sin x$ | $-\cos x + C$ | |
| $\cos x$ | $\sin x + C$ | |
| $k$ (постоянная) | $kx + C$ | |

- **Правило суммы/разности** сохраняется: $\int [f(x) \pm g(x)]\, dx = \int f(x)\, dx \pm \int g(x)\, dx$. Константы можно вытащить: $\int k\, f(x)\, dx = k \int f(x)\, dx$.

- Когда функция слишком сложна для прямой интеграции, у нас есть методы ее упрощения.

- **u-замещение** является обратным правилу цепочки. Если вы заметили составную функцию $f(g(x))$, умноженную на $g'(x)$, замените $u = g(x)$ так, чтобы получилось $du = g'(x)\, dx$, и интеграл упростится.

- Например: $\int 2x \cos(x^2)\, dx$. Пусть $u = x^2$, значит $du = 2x\, dx$. Интеграл принимает вид $\int \cos(u)\, du = \sin(u) + C = \sin(x^2) + C$.

- **Интегрирование по частям** является обратным правилу произведения. Если подынтегральная функция является произведением двух функций:$$\int u\, dv = uv - \int v\, du$$

- Выбирайте $u$ и $dv$ стратегически, чтобы оставшийся интеграл $\int v\, du$ был проще исходного. Обычная мнемоника для выбора $u$ — **LIATE**: логарифмический, обратный тригонометрический, алгебраический, тригонометрический, экспоненциальный (выберите $u$ из предыдущей категории).

- Например: $\int x\, e^x\, dx$. Пусть $u = x$ (алгебраический) и $dv = e^x\, dx$. Затем $du = dx$ и $v = e^x$. Итак: $\int x\, e^x\, dx = x\, e^x - \int e^x\, dx = x\, e^x - e^x + C = e^x(x - 1) + C$.

- В ML интеграция появляется в теории вероятностей (вычисление вероятностей путем интегрирования функций плотности), в ожидаемых значениях (средние взвешенные значения по непрерывным распределениям) и при вычислении площади под кривыми ROC. Хотя на практике мы редко интегрируем вручную, понимание того, что означает интегрирование, помогает интерпретировать эти величины.

## Задачи по кодированию (используйте CoLab или блокнот)

1. Численно аппроксимируйте $\int_0^1 x^2\, dx$, используя сумму Римана с увеличением числа прямоугольников. Сравните с точным ответом $\frac{1}{3}$.
```python
import jax.numpy as jnp

for n in [10, 100, 1000, 10000]:
    x = jnp.linspace(0, 1, n, endpoint=False)
    dx = 1.0 / n
    area = jnp.sum(x**2 * dx)
    print(f"n={n:5d}  approx: {area:.6f}  exact: {1/3:.6f}")
```

2. Проверьте основную теорему исчисления численно. Определите $F(x) = \int_0^x t^2\, dt = \frac{x^3}{3}$ и убедитесь, что его производная (вычисленная с помощью `jax.grad`) равна $x^2$.
```python
import jax
import jax.numpy as jnp

F = lambda x: x**3 / 3
dF = jax.grad(F)

for x in [0.5, 1.0, 2.0, 3.0]:
    print(f"x={x:.1f}  F'(x)={dF(x):.4f}  x^2={x**2:.4f}")
```

3. Визуализируйте область под $f(x) = \sin(x)$ от $0$ до $\pi$. Используйте `plt.fill_between`, чтобы заштриховать область и вычислить ее численно с помощью суммы Римана.
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

x = jnp.linspace(0, jnp.pi, 500)
y = jnp.sin(x)

plt.plot(x, y, color="purple", linewidth=2)
plt.fill_between(x, y, alpha=0.2, color="purple")
plt.title(f"Area = {jnp.sum(jnp.sin(x) * (jnp.pi / 500)):.4f}  (exact: 2.0)")
plt.show()
```
