# Оптимизация

*Оптимизация — это математическое ядро обучения модели, заключающееся в поиске параметров, которые минимизируют функцию потерь. В этом файле описаны критические точки, выпуклость, градиентный спуск, метод Ньютона, оптимизация с ограничениями с помощью множителей Лагранжа и оптимизаторы (SGD, Adam), которые лежат в основе современного глубокого обучения.*

- Обучение нейронной сети, подбор линии регрессии, настройка гиперпараметров: в основе почти каждого алгоритма машинного обучения лежит проблема **оптимизации**. 

- У нас есть некая функция (убыток, стоимость, цель), и мы хотим найти входные данные, которые сделают ее как можно меньше (или больше). 

- Прежде чем оптимизировать, нам нужно понять **нули** (или корни) функций. Ноль $f(x)$ — это значение $x$, где $f(x) = 0$. Графически это x-перехваты.

- Например, $f(x) = x^2 - 3x + 2 = (x-1)(x-2)$ имеет нули по адресам $x = 1$ и $x = 2$. Между нулями функция отрицательна ($f(1.5) = -0.25$); вне нулей оно положительно. Нули делят числовую прямую на области, в которых функция имеет постоянный знак.

- **Кратность** нуля показывает, сколько раз появляется соответствующий множитель. 

- При простом нуле (кратность 1) график пересекает ось X. При двойном нуле (кратность 2) график касается оси X, но отскакивает назад, не пересекая, и в этой точке выглядит «плоским».

- Поиск нулей имеет большое значение, поскольку нули производной $f'(x)$ являются **критическими точками** $f(x)$, кандидатами на максимумы и минимумы. 

- При максимальном или минимальном значении касательная линия является плоской (наклон = 0), поэтому $f'(x) = 0$.

![Critical points: where the derivative equals zero, the function has a peak, valley, or saddle](../images/critical_points.svg)

- Но не каждая критическая точка является максимумом или минимумом. Точка, в которой $f'(x) = 0$ также может быть **точкой перегиба** (например, $x = 0$ для $f(x) = x^3$), где функция на мгновение выравнивается, но не меняет направление.

– Эту проблему решает **тест второй производной**. В критической точке $x = c$, где $f'(c) = 0$:

    - Если $f''(c) > 0$: кривая вогнута вверх (как чаша), поэтому $c$ является **локальным минимумом**.
    - Если $f''(c) < 0$: кривая вогнута вниз (как холм), поэтому $c$ является **локальным максимумом**.
    - Если $f''(c) = 0$: тест не дал результатов; необходимы высшие производные или другие методы.

- Например, $f(x) = x^3 - 3x$. Производная — $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$, поэтому критические точки находятся в точках $x = -1$ и $x = 1$. Вторая производная — $f''(x) = 6x$. По адресу $x = -1$: $f''(-1) = -6 < 0$ (локальный максимум). По адресу $x = 1$: $f''(1) = 6 > 0$ (местный минимум).

- Функция называется **выпуклой**, если отрезок между любыми двумя точками ее графика лежит над графиком (или на нем). Думайте об этом как о форме чаши, повсюду изгибающейся вверх. Математически $f$ является выпуклым, если $f''(x) \geq 0$ для всех $x$.

![Convex functions have a unique global minimum; non-convex functions can have many local minima](../images/convex_nonconvex.svg)

- Выпуклость является мощной силой, поскольку выпуклые функции обладают замечательным свойством: каждый локальный минимум является также **глобальным минимумом**. Здесь нет обманчивых местных долин, в которых можно застрять. Если скатить шарик в выпуклую чашу, он всегда достигнет дна.

- Функция является **вогнутой** (изогнутой вниз), если $-f$ выпуклая. Точки, в которых функция переходит от вогнутой к выпуклой, являются **точками перегиба**, возникающими в месте $f''(x) = 0$.

- **Метод Ньютона** находит нули функций (и, соответственно, критические точки их производных) с помощью касательных линий. Начиная с первоначального предположения $x_0$, оно итеративно уточняет:

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

![Newton's method: follow the tangent line to find a better approximation of the root](../images/newtons_method.svg)

- Идея: по адресу $x_n$ провести касательную и найти, где она пересекает ось X. Эта точка пересечения становится $x_{n+1}$. Для функций с хорошим поведением и хорошей отправной точкой метод Ньютона сходится очень быстро (квадратично, что означает, что количество правильных цифр примерно удваивается на каждом шаге).- Например, чтобы найти $\sqrt{5}$ (ноль $f(x) = x^2 - 5$): $f'(x) = 2x$, то есть $x_{n+1} = x_n - \frac{x_n^2 - 5}{2x_n}$. Начиная с $x_0 = 2$: $x_1 = 2.25$, $x_2 = 2.2361\ldots$, что уже с точностью до четырех знаков после запятой.

- Метод Ньютона может дать сбой, если исходное предположение находится далеко от корня, если $f'(x) = 0$ рядом с корнем или если функция имеет точки перегиба поблизости. Это также требует вычисления производной, что может быть дорогостоящим.

- Для оптимизации (поиска минимумов вместо нулей) применяем метод Ньютона к $f'(x) = 0$, который дает обновление:

$$x_{n+1} = x_n - \frac{f'(x_n)}{f''(x_n)}$$

- В нескольких измерениях это будет $\mathbf{x}_{n+1} = \mathbf{x}_n - H^{-1} \nabla f(\mathbf{x}_n)$, где $H$ — матрица Гессе. Это приближение Тейлора второго порядка из предыдущего файла в действии: аппроксимируйте функцию как квадратичную, перейдите к минимуму этого квадратичного уравнения, повторите.

- **Множители Лагранжа** решают **ограниченную оптимизацию**: найдите оптимум $f(x, y)$ с учетом ограничения $g(x, y) = c$. Вместо поиска по всему $\mathbb{R}^n$ мы ограничиваемся набором, в котором выполняется ограничение (кривая или поверхность).

- Ключевой вывод является геометрическим: при ограниченном оптимуме градиент $f$ должен быть параллелен градиенту $g$. Если бы они не были параллельны, мы могли бы двигаться вдоль ограничения в направлении, которое все еще улучшает $f$, поэтому мы еще не достигли бы оптимума.

- Мы вводим новую переменную $\lambda$ (множитель Лагранжа) и определяем **лагранжиан**:

$$\mathcal{L}(x, y, \lambda) = f(x, y) - \lambda(g(x, y) - c)$$

- Приравнивание всех частных производных к нулю дает систему уравнений, решениями которой являются ограниченные оптимумы:

$$\frac{\partial \mathcal{L}}{\partial x} = 0, \quad \frac{\partial \mathcal{L}}{\partial y} = 0, \quad \frac{\partial \mathcal{L}}{\partial \lambda} = 0$$

![Lagrange multipliers: at the optimum, gradients of f and g are parallel](../images/lagrange_multiplier.svg)

- Например, разверните $f(x,y) = x^2 y$ с учетом $x^2 + y^2 = 1$. Лагранжиан равен $\mathcal{L} = x^2 y - \lambda(x^2 + y^2 - 1)$. Принимая частичные:

$$2xy - 2\lambda x = 0, \quad x^2 - 2\lambda y = 0, \quad x^2 + y^2 = 1$$

- Из первого уравнения (при условии $x \neq 0$): $\lambda = y$. Подставляем во вторую: $x^2 = 2y^2$. В сочетании с ограничением: $2y^2 + y^2 = 1$, получается $y = \frac{1}{\sqrt{3}}$. Максимальное значение — $f = \frac{2}{3\sqrt{3}}$.

- Для ограничений-неравенств ($g(x,y) \leq c$ вместо $= c$) условия **Каруша-Куна-Такера (KKT)** обобщают множители Лагранжа. Ограничение может быть либо активным (связывание, рассматриваемое как равенство), либо неактивным (решение находится внутри, а ограничение не имеет значения).

— На практике мы редко оптимизируем вручную. Вот основные алгоритмические семейства:

    - **Методы первого порядка** (используйте только градиент): градиентный спуск, стохастический градиентный спуск (SGD), Адам. Они дешевы за шаг, но могут медленно сходиться, особенно в плохо обусловленных задачах.

    - **Методы второго порядка** (используйте градиент и гессиан): метод Ньютона сходится быстро, но вычисление и инвертирование гессиана требует больших затрат ($O(n^3)$ для параметров $n$). **Квазиньютоновские методы** (такие как BFGS и L-BFGS) аппроксимируют гессиан, используя только информацию о градиенте, обеспечивая более быструю сходимость, чем методы первого порядка, без полной стоимости методов второго порядка.

    - **Сопряженный градиент**: эффективен для больших разреженных систем, использующих только матрично-векторные произведения вместо хранения полного гессиана.

    - **Гаусс-Ньютон** и **Левенберг-Марквардт**: специализируются на задачах наименьших квадратов (часто встречаются в регрессии), аппроксимируя гессиан через якобиан.

    - **Естественный градиентный спуск**: учитывает геометрию пространства параметров с использованием информационной матрицы Фишера, что может быть более эффективным для вероятностных моделей.

- Выбор оптимизатора зависит от задачи. В глубоком обучении доминируют методы первого порядка (особенно Адама), поскольку число параметров огромно (от миллионов до миллиардов), что делает вычисления Гессиана непрактичными. Для небольших задач с гладкими целями методы второго порядка могут быть значительно быстрее.

1. Примените метод Ньютона, чтобы найти $\sqrt{7}$ (ноль $f(x) = x^2 - 7$). Обратите внимание на быструю сходимость.
```python
import jax.numpy as jnp

f = lambda x: x**2 - 7
df = lambda x: 2*x

x = 3.0  # initial guess
for i in range(6):
    x = x - f(x) / df(x)
    print(f"step {i+1}: x = {x:.10f}  (error: {abs(x - jnp.sqrt(7.0)):.2e})")
```2. Используйте градиентный спуск, чтобы минимизировать $f(x, y) = (x - 3)^2 + (y + 1)^2$. Минимум — $(3, -1)$. Поэкспериментируйте с различными скоростями обучения.
```python
import jax
import jax.numpy as jnp

def f(params):
    x, y = params
    return (x - 3)**2 + (y + 1)**2

grad_f = jax.grad(f)
params = jnp.array([0.0, 0.0])
lr = 0.1

for i in range(20):
    g = grad_f(params)
    params = params - lr * g
    if i % 5 == 0 or i == 19:
        print(f"step {i:2d}: ({params[0]:.4f}, {params[1]:.4f})  loss={f(params):.6f}")
```

3. Решите задачу оптимизации с ограничениями численно. Максимизируйте $f(x,y) = xy$ с учетом $x + y = 10$ путем параметризации $y = 10 - x$ и нахождения оптимума функции с одной переменной.
```python
import jax
import jax.numpy as jnp

# Substitute constraint: y = 10 - x, so f = x(10 - x) = 10x - x²
f = lambda x: x * (10 - x)
df = jax.grad(f)

# Gradient ascent (we want maximum, so add gradient)
x = 1.0
lr = 0.1
for i in range(20):
    x = x + lr * df(x)
print(f"x={x:.4f}, y={10-x:.4f}, f={f(x):.4f}")  # should be x=5, y=5, f=25
```
